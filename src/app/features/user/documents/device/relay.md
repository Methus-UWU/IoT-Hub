> **คำเตือนด้านความปลอดภัย** ฝั่งหน้าสัมผัสของรีเลย์ใช้กับไฟบ้าน 220 V ได้ การสัมผัสขั้ว
> ขณะจ่ายไฟอาจถึงแก่ชีวิต ต่อสายฝั่งไฟบ้านในกล่องปิดเท่านั้น ถอดปลั๊กทุกครั้งก่อนแก้ไขสาย
> และถ้าไม่เคยต่อวงจรไฟบ้านมาก่อน ให้มีผู้มีประสบการณ์ตรวจงานก่อนจ่ายไฟ

## ภาพรวม

รีเลย์คือสวิตช์ที่ใช้แม่เหล็กไฟฟ้าดันหน้าสัมผัสให้แตะกัน วงจรควบคุมแรงดันต่ำจึงสั่งเปิดปิด
วงจรแรงดันสูงได้โดยไม่ต่อถึงกันทางไฟฟ้า โมดูลที่ใช้ในระบบนี้มีออปโตคัปเปลอร์คั่นอีกชั้น
มีรุ่น 1, 2, 4 และ 8 ช่อง ทุกช่องทำงานเหมือนกัน ต่างกันแค่จำนวน

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| แรงดันขดลวด | 5 V |
| กระแสต่อช่องขณะทำงาน | ราว 70 mA |
| หน้าสัมผัสรับได้ | 10 A ที่ 250 V ไฟสลับ หรือ 10 A ที่ 30 V ไฟตรง |
| อายุการใช้งาน | ราว 100,000 ครั้งเมื่อมีโหลด |

## กระแสรวมคือข้อจำกัดจริง

แต่ละช่องกิน 70 mA ดังนั้นบอร์ด 4 ช่องที่ทำงานพร้อมกันกิน 280 mA และ 8 ช่องกิน 560 mA
ซึ่งเกินที่ขา `5V` ของบอร์ดพัฒนาจ่ายได้ อาการคือบอร์ดรีสตาร์ตทันทีที่สั่งรีเลย์หลายช่องพร้อมกัน
บอร์ด 4 ช่องขึ้นไปต้องใช้แหล่งจ่ายไฟแยก ถอดจัมเปอร์ `JD-VCC` ออกแล้วต่อไฟแยกเข้าที่ขานั้น
โดยยังต่อกราวด์ร่วมกับบอร์ดควบคุม

## ขาฝั่งหน้าสัมผัส

| ขา | ความหมาย |
| --- | --- |
| `COM` | ขั้วร่วม ต่อสายไฟเส้นที่ต้องการตัดต่อ |
| `NO` | ปกติเปิดวงจร ต่อถึง `COM` เมื่อรีเลย์ทำงาน |
| `NC` | ปกติปิดวงจร ตัดออกจาก `COM` เมื่อรีเลย์ทำงาน |

งานเปิดปิดอุปกรณ์ทั่วไปใช้ `COM` กับ `NO` เพื่อให้ไฟดับเมื่อบอร์ดไม่ทำงานหรือไฟตก

## โมดูลส่วนใหญ่ทำงานเมื่อสัญญาณต่ำ

บอร์ดรีเลย์ที่ขายกันทั่วไปเป็นแบบ active-low คือรีเลย์ทำงานเมื่อขา `IN` ถูกดึงลงต่ำ บางรุ่นมีจัมเปอร์
`H/L` ให้เลือกทำงานเมื่อสัญญาณสูงได้ ในอุปกรณ์จำลองตั้งได้ที่แผงด้านขวา หัวข้อ "สั่งงานด้วย" LOW หรือ HIGH

```cpp
const int RELAY_PIN = 26;

void setup() {
  // ตั้งค่าให้ดับก่อนแล้วค่อยตั้งโหมดขา ไม่งั้นรีเลย์จะติดแวบหนึ่งตอนบอร์ดบูต
  digitalWrite(RELAY_PIN, HIGH);
  pinMode(RELAY_PIN, OUTPUT);
}

void turnOn() {
  digitalWrite(RELAY_PIN, LOW);
}

void turnOff() {
  digitalWrite(RELAY_PIN, HIGH);
}
```

ลำดับใน `setup()` สำคัญ ถ้าเรียก `pinMode` ก่อน ขาจะเป็นลอจิกต่ำอยู่ครู่หนึ่ง ซึ่งพอให้รีเลย์
ติดแล้วดับทุกครั้งที่บอร์ดรีสตาร์ต ปั๊มน้ำหรือมอเตอร์ที่ติดแวบแบบนี้ทุกครั้งเป็นปัญหาจริง

## ปัญหาที่พบบ่อย

- **บอร์ดรีสตาร์ตตอนรีเลย์ทำงาน** ไฟไม่พอ ใช้แหล่งจ่ายแยกตามหัวข้อข้างบน
- **รีเลย์ติดสลับกับที่สั่ง** โมดูลเป็นแบบ active-low กลับตรรกะในโค้ด
- **ได้ยินเสียงคลิกแต่โหลดไม่ทำงาน** ต่อสายไฟบ้านเข้าที่ `NC` แทน `NO`
- **รีเลย์สั่นถี่ ๆ** แรงดันขดลวดตกจนไม่พอค้างหน้าสัมผัส มักเกิดจากสายไฟเส้นเล็กเกินไป
- **หน้าสัมผัสไหม้ติดกัน** โหลดกินกระแสเกินพิกัด หรือเป็นโหลดแบบมอเตอร์ที่กระแสตอนสตาร์ต
  สูงกว่าตอนทำงานหลายเท่า
