## ภาพรวม

โมดูลตรวจจับสิ่งกีดขวางแบบอินฟราเรด มี LED อินฟราเรดยิงแสงออกไปและโฟโตทรานซิสเตอร์รับ
แสงที่สะท้อนกลับ ถ้าได้รับแสงสะท้อนมากพอ แปลว่ามีวัตถุอยู่ข้างหน้า

**บอกได้แค่ว่ามีของหรือไม่มี วัดระยะไม่ได้** งานที่ต้องรู้ระยะจริงต้องใช้ HC-SR04

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| แรงดัน | 3.3–5 V |
| ระยะตรวจจับ | 2–30 ซม. ปรับได้ |
| มุมตรวจจับ | ราว 35 องศา |
| สัญญาณออก | ดิจิทัล ต่ำเมื่อเจอวัตถุ |
| กระแส | ราว 20 mA |

## สัญญาณออกกลับด้านจากที่คาด

ขา `OUT` ให้ค่า **`LOW` เมื่อเจอวัตถุ** และ `HIGH` เมื่อไม่เจอ ตรงข้ามกับสัญชาตญาณ ไฟ LED
ดวงที่สองบนบอร์ดจะติดเมื่อเจอวัตถุ ใช้ดูตอนปรับตั้งได้สะดวก

```cpp
const int IR_PIN = 14;

void setup() {
  pinMode(IR_PIN, INPUT);
}

bool obstacleAhead() {
  return digitalRead(IR_PIN) == LOW;
}
```

โมดูลนี้เป็นดิจิทัลล้วน จึงไม่มีปัญหาเรื่องขา ADC2 กับ Wi-Fi และต่อเข้าขา GPIO ใดก็ได้

## สีและพื้นผิวมีผลมาก

ปริมาณแสงที่สะท้อนกลับขึ้นกับผิววัตถุโดยตรง

| ผิว | ผลลัพธ์ |
| --- | --- |
| ขาวด้าน | สะท้อนดีที่สุด ตรวจได้ไกลสุด |
| สีอ่อนทั่วไป | ตรวจได้ตามปกติ |
| สีดำด้าน | สะท้อนน้อยมาก มักตรวจไม่เจอ |
| กระจกหรือโลหะเงา | สะท้อนออกไปทางอื่น ตรวจไม่เจอ |

หุ่นยนต์เดินตามเส้นใช้คุณสมบัตินี้โดยตรง เส้นดำบนพื้นขาวให้ผลต่างที่ชัดเจน

## แสงแดดรบกวน

แสงแดดมีอินฟราเรดมาก ทำให้โฟโตทรานซิสเตอร์อิ่มตัวจนตรวจอะไรไม่ได้เลย โมดูลนี้ใช้กลางแจ้ง
แทบไม่ได้ ถ้าจำเป็นต้องบังแสงรอบตัวเซนเซอร์ด้วยท่อสั้น ๆ

## การปรับระยะ

หมุนตัวต้านทานปรับค่าบนบอร์ดทีละน้อย โดยวางวัตถุไว้ที่ระยะที่ต้องการตรวจ แล้วหมุนจนไฟ LED
เพิ่งจะติด จากนั้นถอยวัตถุออกเพื่อยืนยันว่าไฟดับ

ระยะที่ตั้งได้ไกลสุดราว 30 ซม. และยิ่งตั้งไกลยิ่งไวต่อการรบกวนจากแสงรอบข้าง

## ปัญหาที่พบบ่อย

- **ตรวจเจอตลอดเวลา** ปรับความไวสูงเกินไป หรือมีวัตถุอยู่ในระยะโดยไม่รู้ตัว
- **ไม่เจอวัตถุสีดำ** ข้อจำกัดของหลักการทำงาน ใช้ HC-SR04 แทน
- **ทำงานในร่มแต่ไม่ทำงานกลางแจ้ง** แสงแดดรบกวน
- **ตรรกะกลับด้าน** `LOW` คือเจอวัตถุ ไม่ใช่ `HIGH`
- **โมดูลสองตัวรบกวนกัน** วางใกล้กันเกินไป แสงจากตัวหนึ่งเข้าอีกตัว ให้หันคนละทางหรือสลับ
  กันเปิดทีละตัว
