## ภาพรวม

เซนเซอร์ตรวจจับความร้อนอินฟราเรดแบบพาสซีฟ ไม่ได้ยิงอะไรออกไป แต่รอรับรังสีความร้อนจาก
ร่างกายคนหรือสัตว์ เลนส์เฟรสเนลสีขาวด้านหน้าแบ่งมุมมองออกเป็นหลายโซน เมื่อวัตถุที่อุ่นกว่า
สภาพแวดล้อมเคลื่อนข้ามโซน เซนเซอร์จะเห็นความต่างและส่งสัญญาณออก

**เซนเซอร์นี้ตรวจจับการเคลื่อนไหว ไม่ใช่การมีอยู่** คนที่นั่งนิ่งจะหายไปจากการตรวจจับ

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| แรงดัน | 4.5–20 V |
| แรงดันสัญญาณออก | 3.3 V |
| ระยะตรวจจับ | 3–7 เมตร ปรับได้ |
| มุมตรวจจับ | 110 องศา |
| เวลาอุ่นเครื่อง | 30–60 วินาที |

สัญญาณออก 3.3 V จึงต่อเข้า ESP32 ได้ตรงโดยไม่ต้องลดแรงดัน

## ตัวปรับสองตัวและจัมเปอร์

บนบอร์ดมีตัวต้านทานปรับค่าสองตัว

| ตัวปรับ | หน้าที่ |
| --- | --- |
| `Sx` หรือตัวใกล้ขอบ | ความไว ปรับระยะตรวจจับ 3–7 เมตร |
| `Tx` | ระยะเวลาที่สัญญาณค้างสูงหลังตรวจเจอ 5 วินาที ถึง 5 นาที |

จัมเปอร์สามขาเลือกโหมด

- **`H` โหมดค้าง** ตรวจเจอซ้ำระหว่างที่สัญญาณยังสูงอยู่ จะนับเวลาใหม่ ใช้กับงานเปิดไฟ
- **`L` โหมดครั้งเดียว** สัญญาณลงต่ำเมื่อครบเวลาเสมอ แล้วจึงจะตรวจใหม่ได้

งานเปิดไฟอัตโนมัติควรใช้โหมด `H` ไม่งั้นไฟจะดับทั้งที่คนยังอยู่ในห้อง

## ช่วงอุ่นเครื่องต้องข้าม

หลังจ่ายไฟ เซนเซอร์ต้องใช้เวลาปรับตัวเข้ากับความร้อนพื้นหลังราวหนึ่งนาที ระหว่างนี้จะส่งสัญญาณ
หลอกเป็นระยะ โค้ดต้องไม่เชื่อค่าในช่วงนี้

```cpp
const int PIR_PIN = 27;
const unsigned long WARMUP_MS = 60000;

void setup() {
  pinMode(PIR_PIN, INPUT);
}

bool motionDetected() {
  if (millis() < WARMUP_MS) return false;   // ข้ามช่วงอุ่นเครื่อง
  return digitalRead(PIR_PIN) == HIGH;
}
```

## สิ่งที่ทำให้แจ้งเตือนผิด

- ลมร้อนจากเครื่องปรับอากาศหรือพัดลมที่เป่าผ่านหน้าเซนเซอร์
- แสงแดดที่ส่องเข้ามาแล้วเคลื่อนตามเวลา
- สัตว์เลี้ยง ซึ่งเซนเซอร์แยกจากคนไม่ได้
- ตัวเซนเซอร์เองสั่นหรือขยับ เพราะพื้นหลังทั้งภาพเปลี่ยนพร้อมกัน

ติดตั้งให้พ้นทางลม พ้นแสงแดดตรง และยึดให้แน่นไม่สั่น

## ปัญหาที่พบบ่อย

- **สัญญาณสูงค้างตลอด** ยังอยู่ในช่วงอุ่นเครื่อง หรือมีแหล่งความร้อนเคลื่อนไหวอยู่ในมุมมอง
- **ตรวจไม่เจอทั้งที่มีคนเดินผ่าน** ความไวต่ำเกินไป หรือคนเดินตรงเข้าหาเซนเซอร์ ซึ่งข้ามโซน
  น้อยกว่าการเดินตัดขวาง
- **ระยะไกลกว่าที่ต้องการมาก** ลดความไว หรือติดกระดาษบังบางส่วนของเลนส์
