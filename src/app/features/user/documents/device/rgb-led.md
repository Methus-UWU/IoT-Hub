## ภาพรวม

LED สามดวงคือแดง เขียว น้ำเงิน อยู่ในตัวถังใสเดียวกัน มีสี่ขา โดยขาหนึ่งเป็นขาร่วมของทั้งสามสี
ผสมความสว่างของแต่ละสีด้วย PWM จะได้สีตามต้องการ

## สองแบบที่ต้องแยกให้ออก

| หัวข้อ | แคโทดร่วม | แอโนดร่วม |
| --- | --- | --- |
| ขาร่วมต่อไปที่ | กราวด์ | ไฟบวก |
| ค่า 255 หมายถึง | สว่างเต็มที่ | ดับสนิท |
| ค่า 0 หมายถึง | ดับสนิท | สว่างเต็มที่ |

ทดสอบแยกได้ด้วยการต่อขาร่วมลงกราวด์ผ่านตัวต้านทาน ถ้าติดคือแบบแคโทดร่วม

## ขาเรียงอย่างไร

ขาที่ยาวที่สุดคือขาร่วม เรียงจากด้านที่มีขาเดียวก่อนขายาว จะได้ **แดง ขาร่วม เขียว น้ำเงิน**

## ต้องมีตัวต้านทานสามตัว

ใส่ตัวต้านทานที่ขาสีทั้งสามแยกกัน **ห้ามใช้ตัวเดียวที่ขาร่วม** เพราะกระแสที่ไหลผ่านตัวนั้นจะถูก
แบ่งระหว่างสีที่ติดอยู่ ทำให้ความสว่างเปลี่ยนตามจำนวนสีที่เปิด สีขาวจะจางกว่าสีเดี่ยวอย่างชัดเจน

แต่ละสีมีแรงดันตกคร่อมต่างกัน สีแดงราว 2.0 V ส่วนเขียวและน้ำเงินราว 3.0 V ถ้าใช้ตัวต้านทาน
ค่าเท่ากันทั้งสามขา สีแดงจะสว่างกว่าสองสีที่เหลือ ใช้ค่าสูงกว่าที่ขาแดงจะช่วยให้สมดุลขึ้น

| ขา | ค่าที่แนะนำกับ 3.3 V |
| --- | --- |
| แดง | 220 Ω |
| เขียว | 100 Ω |
| น้ำเงิน | 100 Ω |

## ตัวอย่างโค้ด

```cpp
const int RED_PIN = 25;
const int GREEN_PIN = 26;
const int BLUE_PIN = 27;
const bool COMMON_ANODE = false;

void setColor(int red, int green, int blue) {
  if (COMMON_ANODE) {
    red = 255 - red;
    green = 255 - green;
    blue = 255 - blue;
  }
  analogWrite(RED_PIN, red);
  analogWrite(GREEN_PIN, green);
  analogWrite(BLUE_PIN, blue);
}

void showStatus(bool online) {
  if (online) setColor(0, 180, 0);      // เขียว
  else setColor(200, 60, 0);            // ส้ม
}
```

การรวมการกลับค่าไว้ในฟังก์ชันเดียว ทำให้เปลี่ยนระหว่าง LED สองแบบได้โดยแก้ค่าคงที่ตัวเดียว

## สีที่ได้ไม่ตรงกับที่ตั้ง

ค่าตัวเลข RGB เดียวกันให้สีต่างกันในแต่ละหลอด เพราะประสิทธิภาพของแต่ละสีไม่เท่ากันและ
สายตาคนไวต่อสีเขียวมากที่สุด สีขาวจากค่า `255, 255, 255` มักออกฟ้าหรือเขียว ต้องปรับค่า
ด้วยตาจนได้สีที่ต้องการ

## ปัญหาที่พบบ่อย

- **ติดตลอดเวลาและดับไม่ได้** ใช้แบบแอโนดร่วมแต่เขียนโค้ดแบบแคโทดร่วม
- **สีขาวจางกว่าสีเดี่ยว** ใช้ตัวต้านทานตัวเดียวที่ขาร่วม
- **สีแดงกลบสีอื่นหมด** ตัวต้านทานที่ขาแดงค่าต่ำเกินไป
- **สีไม่เปลี่ยนตามค่าที่สั่ง** ต่อขาสีสลับกัน ทดสอบทีละสีก่อน
