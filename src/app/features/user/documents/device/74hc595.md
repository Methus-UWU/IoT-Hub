## ภาพรวม

ชิฟต์รีจิสเตอร์ที่รับข้อมูลแบบอนุกรมทีละบิต แล้วส่งออกพร้อมกันแปดขา ใช้ขาของบอร์ดเพียงสาม
ขาแลกกับเอาต์พุตแปดขา และต่อพ่วงกันได้เรื่อย ๆ โดยยังใช้สามขาเท่าเดิม

## ขาที่ต้องต่อ

| ขา | ชื่อในเอกสาร | หน้าที่ |
| --- | --- | --- |
| 14 | `DS` | ข้อมูลเข้า ทีละบิต |
| 11 | `SHCP` | สัญญาณนาฬิกา เลื่อนบิตเข้าไปหนึ่งตำแหน่ง |
| 12 | `STCP` | สัญญาณล็อก ย้ายข้อมูลออกไปที่ขาเอาต์พุตพร้อมกัน |
| 10 | `MR` | รีเซ็ต ต่อไฟบวกค้างไว้เพื่อไม่ให้รีเซ็ต |
| 13 | `OE` | เปิดใช้เอาต์พุต ต่อกราวด์ค้างไว้เพื่อให้ทำงาน |
| 8 | `GND` | กราวด์ |
| 16 | `VCC` | ไฟเลี้ยง 2–6 V |
| 15, 1–7 | `Q0`–`Q7` | เอาต์พุตแปดขา |

ขา `MR` และ `OE` ต้องต่อทุกครั้ง ปล่อยลอยไว้แล้วชิปจะทำงานแบบสุ่ม

## หลักการทำงาน

ข้อมูลเข้าที่ `DS` ทีละบิต แต่ละครั้งที่ `SHCP` มีขอบขาขึ้น บิตทั้งหมดจะเลื่อนไปหนึ่งตำแหน่ง
เอาต์พุตยังไม่เปลี่ยนจนกว่าจะสั่ง `STCP` ซึ่งย้ายค่าทั้งหมดออกไปพร้อมกัน

การแยกสองจังหวะนี้สำคัญ ถ้าเอาต์พุตเปลี่ยนตามทุกบิตที่เลื่อนเข้าไป LED จะกะพริบวูบวาบระหว่าง
ส่งข้อมูล

## ตัวอย่างโค้ด

```cpp
const int DATA_PIN = 25;
const int CLOCK_PIN = 26;
const int LATCH_PIN = 27;

void setup() {
  pinMode(DATA_PIN, OUTPUT);
  pinMode(CLOCK_PIN, OUTPUT);
  pinMode(LATCH_PIN, OUTPUT);
}

void writeOutputs(byte value) {
  digitalWrite(LATCH_PIN, LOW);              // ปิดล็อกก่อนส่ง
  shiftOut(DATA_PIN, CLOCK_PIN, MSBFIRST, value);
  digitalWrite(LATCH_PIN, HIGH);             // ย้ายออกพร้อมกันทั้งแปดขา
}

void runningLight() {
  for (int i = 0; i < 8; i++) {
    writeOutputs(1 << i);
    delay(100);
  }
}
```

## กระแสรวมคือข้อจำกัด

แต่ละขาจ่ายได้ 35 mA แต่ **รวมทุกขาต้องไม่เกิน 70 mA** ต่อ LED แปดดวงดวงละ 20 mA แล้ว
สั่งติดพร้อมกันคือ 160 mA ซึ่งเกินไปมาก ชิปจะร้อนและพังในที่สุด

ทางแก้: ใช้ตัวต้านทานค่าสูงขึ้นเพื่อลดกระแสต่อดวงเหลือ 5–8 mA หรือขับ LED ผ่านทรานซิสเตอร์
แล้วให้ชิปสั่งเฉพาะขาเบส

## ต่อพ่วงหลายตัว

ขา `Q7S` ขา 9 คือข้อมูลที่ล้นออกจากตัวแรก ต่อเข้าขา `DS` ของตัวถัดไป ส่วน `SHCP` และ
`STCP` ต่อขนานกันทุกตัว จากนั้นส่งข้อมูลสองไบต์ติดกันโดยส่งไบต์ของตัวปลายทางก่อน

## ปัญหาที่พบบ่อย

- **เอาต์พุตเปลี่ยนแบบสุ่ม** ขา `MR` หรือ `OE` ลอย
- **LED กะพริบระหว่างอัปเดต** ลืมปิดล็อกก่อนส่งข้อมูล
- **ลำดับบิตกลับด้าน** เปลี่ยนระหว่าง `MSBFIRST` กับ `LSBFIRST`
- **ชิปร้อน** กระแสรวมเกิน 70 mA
- **ตัวที่สองไม่ทำงาน** ต่อจากขา `Q7` แทนที่จะเป็น `Q7S` ขา 9
