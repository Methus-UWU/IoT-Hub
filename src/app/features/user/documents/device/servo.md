## ภาพรวม

เซอร์โวคือมอเตอร์ที่มีเฟืองทด ตัวต้านทานปรับค่าวัดตำแหน่ง และวงจรควบคุมรวมอยู่ในตัวถังเดียว
สั่งเป็นมุมได้โดยตรงและตัวมันจะรักษามุมนั้นไว้เอง SG90 เป็นรุ่นเล็กที่ใช้กับงานทั่วไป

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| ช่วงมุม | 0–180 องศา |
| แรงบิด | 1.8 กก.·ซม. ที่ 4.8 V |
| ความเร็ว | 0.1 วินาทีต่อ 60 องศา |
| กระแสขณะอยู่นิ่ง | 5–10 mA |
| กระแสขณะหมุน | 100–250 mA |
| กระแสตอนติดขัด | สูงถึง 700 mA |
| เฟือง | พลาสติก |

## สายทั้งสามเส้น

| สี | หน้าที่ |
| --- | --- |
| น้ำตาลหรือดำ | กราวด์ |
| แดง | ไฟเลี้ยง 4.8–6 V |
| ส้มหรือเหลือง | สัญญาณควบคุม |

## ต้องใช้แหล่งจ่ายไฟแยก

กระแสตอนติดขัดถึง 700 mA เกินที่ขา `5V` ของบอร์ดพัฒนาจ่ายได้มาก ต่อสายแดงเข้าขา `5V`
ของบอร์ดแล้วบอร์ดจะรีสตาร์ตทุกครั้งที่เซอร์โวออกแรง ให้ใช้แหล่งจ่ายแยก แล้ว **ต่อกราวด์ของ
แหล่งจ่ายนั้นเข้ากับกราวด์ของบอร์ดด้วย** ไม่ต่อกราวด์ร่วมกันคือสาเหตุที่พบบ่อยที่สุดที่เซอร์โว
สั่นไม่หยุดหรือไม่ขยับเลย

การใส่ตัวเก็บประจุอิเล็กโทรไลต์ 470 µF คร่อมไฟเลี้ยงของเซอร์โวช่วยลดแรงดันตกตอนเริ่มหมุน
ได้มาก

## สัญญาณควบคุม

เซอร์โวอ่านความกว้างของพัลส์ที่ส่งซ้ำทุก 20 มิลลิวินาที พัลส์กว้าง 1000 ไมโครวินาทีคือมุม 0
องศา 1500 คือ 90 องศา และ 2000 คือ 180 องศา แต่ละตัวคลาดเคลื่อนต่างกัน จึงมักต้องปรับ
ช่วงเล็กน้อยให้ตรงกับตัวที่ใช้จริง

```cpp
#include <ESP32Servo.h>

Servo gate;

void setup() {
  gate.setPeriodHertz(50);
  gate.attach(13, 500, 2400);  // ขา, ความกว้างต่ำสุด, สูงสุด (ไมโครวินาที)
  gate.write(0);
}

void openGate() {
  gate.write(90);
  delay(500);   // รอให้หมุนถึงมุมก่อนสั่งงานถัดไป
}
```

ค่า 500 กับ 2400 คือช่วงที่ SG90 ส่วนใหญ่ตอบสนองได้เต็มช่วง ค่าปริยายของไลบรารีมักแคบกว่า
ทำให้หมุนไม่ครบ 180 องศา

## ห้ามฝืนแกนด้วยมือ

การหมุนแกนด้วยมือขณะจ่ายไฟทำให้วงจรควบคุมสู้กลับด้วยกระแสเต็มที่ เฟืองพลาสติกของ SG90
บิ่นได้ง่ายมากจากแรงนี้ ถ้าต้องตั้งตำแหน่งด้วยมือให้ตัดไฟก่อน

## ปัญหาที่พบบ่อย

- **สั่นตลอดเวลา** ไม่ได้ต่อกราวด์ร่วม หรือไฟเลี้ยงไม่พอ
- **หมุนไม่ครบช่วง** ปรับค่าความกว้างพัลส์ต่ำสุด/สูงสุดใน `attach`
- **ร้อนจัดขณะอยู่นิ่ง** แกนถูกฝืนอยู่ ตรวจว่าชิ้นงานติดขัดหรือสั่งเกินมุมที่กลไกไปได้
- **บอร์ดรีสตาร์ตทุกครั้งที่สั่งหมุน** ใช้แหล่งจ่ายแยก
- **ขยับแล้วค้าง ไม่รับคำสั่งถัดไป** โค้ดสั่งมุมใหม่เร็วเกินไป ต้องเผื่อเวลาให้หมุนถึงก่อน
