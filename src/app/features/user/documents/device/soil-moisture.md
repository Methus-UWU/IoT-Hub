## ภาพรวม

วัดความชื้นในดินจากความนำไฟฟ้าระหว่างขั้วสองขั้วที่ปักลงดิน ดินเปียกนำไฟฟ้าดีกว่าดินแห้ง
ค่าความต้านทานที่วัดได้จึงลดลงเมื่อดินชื้นขึ้น

## ค่าที่อ่านได้กลับด้านกับความชื้น

**ค่า ADC สูง = ดินแห้ง ค่าต่ำ = ดินเปียก** เพราะแรงดันตกคร่อมตัวแบ่งแรงดันลดลงเมื่อความ
ต้านทานของดินลดลง ตรงนี้ทำให้สับสนบ่อยที่สุด แนะนำให้แปลงเป็นเปอร์เซ็นต์ก่อนใช้งาน

```cpp
const int SOIL_PIN = 35;     // ต้องเป็นขา ADC1
const int DRY_VALUE = 3200;  // วัดตอนเซนเซอร์อยู่ในอากาศ
const int WET_VALUE = 1400;  // วัดตอนจุ่มน้ำถึงระดับที่ปักจริง

int moisturePercent() {
  int raw = analogRead(SOIL_PIN);
  int percent = map(raw, DRY_VALUE, WET_VALUE, 0, 100);
  return constrain(percent, 0, 100);
}
```

ค่า `DRY_VALUE` และ `WET_VALUE` ต่างกันในแต่ละตัวและแต่ละชนิดดิน ต้องวัดเองก่อนใช้จริง

## ขั้วโลหะเปลือยจะกร่อน

การจ่ายไฟค้างไว้ทำให้เกิดปฏิกิริยาไฟฟ้าเคมีที่ขั้ว ขั้วจะกร่อนจนอ่านค่าไม่ได้ภายในไม่กี่สัปดาห์
ถ้าปักไว้ในดินชื้นตลอด วิธีแก้คือจ่ายไฟเฉพาะตอนอ่านค่า

```cpp
const int SOIL_POWER_PIN = 26;

int readSoil() {
  digitalWrite(SOIL_POWER_PIN, HIGH);
  delay(300);                        // รอให้ค่านิ่งก่อนอ่าน
  int value = analogRead(SOIL_PIN);
  digitalWrite(SOIL_POWER_PIN, LOW);
  return value;
}
```

การอ่านทุก 30 นาทีก็เพียงพอสำหรับงานรดน้ำต้นไม้ ความชื้นในดินไม่ได้เปลี่ยนเร็วขนาดต้องอ่าน
ทุกวินาที การจ่ายไฟ 300 มิลลิวินาทีทุกครึ่งชั่วโมงยืดอายุเซนเซอร์จากสัปดาห์เป็นปี

## เซนเซอร์แบบเก็บประจุดีกว่า

ถ้าหาได้ ให้ใช้เซนเซอร์แบบเก็บประจุซึ่งขั้วเคลือบฉนวนไว้ ไม่มีโลหะสัมผัสดินโดยตรงจึงไม่กร่อนเลย
ราคาสูงกว่าเล็กน้อยแต่ใช้ได้นานกว่ามาก คลังนี้มีทั้งสองแบบ คือ FC-28 ขั้วเปลือย และ Capacitive
Soil Moisture Sensor v1.2

## การติดตั้ง

ปักให้ลึกถึงระดับรากที่ต้องการวัด และปักในแนวดิ่ง ไม่ใช่เอียง เพราะรอยต่อระหว่างขั้วกับสายเป็น
จุดที่น้ำเข้าได้ง่ายที่สุด ถ้าอยู่กลางแจ้งต้องหุ้มรอยต่อนั้นด้วยกาวซิลิโคน

วัดจุดเดียวไม่ได้บอกทั้งแปลง ดินแห้งไม่เท่ากันในระยะไม่กี่สิบเซนติเมตร แปลงใหญ่ควรมีหลายจุด

## ปัญหาที่พบบ่อย

- **ค่าไม่เปลี่ยนเลยไม่ว่าดินจะแห้งหรือเปียก** ขั้วกร่อนแล้ว หรือสายขาดที่รอยต่อ
- **เปอร์เซ็นต์ติดลบหรือเกิน 100** ค่าปรับเทียบไม่ตรงกับดินจริง วัดใหม่
- **ค่ากระโดดหลังรดน้ำทันที** น้ำยังไม่ซึมทั่ว รอสัก 10 นาทีค่อยอ่าน
- **ค่าเพี้ยนเมื่อใส่ปุ๋ย** ปุ๋ยเพิ่มเกลือแร่ในดินซึ่งเพิ่มความนำไฟฟ้า เซนเซอร์แยกจากน้ำไม่ได้
