> **คำเตือน** เซนเซอร์ตระกูลนี้ไม่ใช่อุปกรณ์นิรภัยที่ผ่านการรับรอง ห้ามใช้เป็นเครื่องเตือนแก๊สพิษหรือ
> แก๊สรั่วตัวเดียวในที่ที่ชีวิตขึ้นอยู่กับมัน ใช้เป็นงานทดลองหรือเป็นชั้นเสริมจากเครื่องที่ได้มาตรฐาน

## ภาพรวม

MQ ทุกรุ่นมีโครงสร้างเดียวกัน คือเม็ดดีบุกไดออกไซด์ที่ถูกทำให้ร้อนด้วยไส้ในตัว อยู่หลังตะแกรง
สแตนเลสสองชั้น สิ่งที่ต่างกันคือสารที่เติมในเม็ด ซึ่งกำหนดว่าไวต่อแก๊สชนิดไหน

| รุ่น | ไวต่อ | ช่วงตรวจจับโดยประมาณ |
| --- | --- | --- |
| MQ-2 | แก๊สหุงต้ม มีเทน ควัน | 200–10000 ppm |
| MQ-3 | ไอแอลกอฮอล์ | 0.04–4 mg/L (ราว 20–2000 ppm) |
| MQ-7 | คาร์บอนมอนอกไซด์ (CO) | 20–2000 ppm |
| MQ-135 | แอมโมเนีย เบนซีน แอลกอฮอล์ ควัน | 10–1000 ppm |

ทุกรุ่นในคลังนี้มาบนบอร์ด LM393 แบบเดียวกัน มีขา `AO` เป็นค่าแอนะล็อก และขา `DO` ที่เป็น LOW
เมื่อค่าเกินจุดที่ตั้งไว้ด้วยตัวต้านทานปรับค่าบนบอร์ด

**ทุกรุ่นแยกชนิดแก๊สไม่ได้** MQ-135 ที่ขึ้นสูงบอกได้แค่ว่าอากาศมีสิ่งปนเปื้อนมากขึ้น ไม่ได้บอกว่า
เป็นแอมโมเนียหรือควัน

## สิ่งที่เหมือนกันทุกรุ่น

- **กินไฟ** ไส้ร้อนกินราว 150 mA ตลอดเวลา จ่ายจากขา `5V` ของบอร์ดพัฒนาหลายตัวพร้อมกันไม่พอ
- **เผาไส้ครั้งแรก** เซนเซอร์ใหม่ต้องจ่ายไฟทิ้งไว้ 24–48 ชั่วโมงก่อนค่าจะนิ่ง
- **อุ่นเครื่องทุกครั้ง** หลังเปิดไฟต้องรออย่างน้อย 20 วินาทีถึงไม่กี่นาทีก่อนอ่านค่า
- **ค่าสัมพัทธ์** ค่าที่อ่านได้ไม่ใช่ ppm การแปลงเป็น ppm ต้องปรับเทียบกับแก๊สที่รู้ความเข้มข้น
- **ความชื้นและอุณหภูมิ** ทำให้ค่าเปลี่ยนได้ แม้แก๊สจะเท่าเดิม

## อ่านค่าแบบเทียบกับอากาศสะอาด

วิธีที่ใช้ได้จริงโดยไม่ต้องมีแก๊สมาตรฐาน คือวัดค่าพื้นฐานในอากาศสะอาดหลังอุ่นเครื่อง แล้วเตือน
เมื่อค่าสูงกว่านั้นมาก

```cpp
const int MQ_PIN = 34;       // ต้องเป็นขา ADC1
int baseline = 0;

void calibrate() {
  long total = 0;
  for (int i = 0; i < 100; i++) {
    total += analogRead(MQ_PIN);
    delay(50);
  }
  baseline = total / 100;    // วัดในอากาศสะอาดเท่านั้น
}

bool elevated() {
  return analogRead(MQ_PIN) > baseline * 1.5;
}
```

ตัวคูณ `1.5` เป็นจุดเริ่มต้น ปรับตามสภาพจริง ถ้าเตือนบ่อยเกินให้เพิ่ม ถ้าไม่เตือนเลยให้ลด

## MQ-7 ต้องการรอบร้อนเย็น

ตามเอกสารของผู้ผลิต MQ-7 ต้องสลับไฟไส้ร้อนเป็นรอบ คือ 5 V นาน 60 วินาทีเพื่อไล่แก๊สออก แล้ว
1.4 V นาน 90 วินาทีระหว่างวัด ค่าที่ถูกต้องอ่านได้ช่วงท้ายของรอบ 1.4 V

บอร์ดสำเร็จรูปแทบทุกรุ่นจ่าย 5 V ค้างไว้ตลอด ค่าจึงยังขึ้นลงตาม CO ได้ แต่ใช้ได้แค่เป็นค่าสัมพัทธ์
งานที่ต้องการค่าตามเอกสารต้องคุมไส้ร้อนเองผ่านทรานซิสเตอร์และ PWM

## MQ-135 กับค่า CO2

โค้ดตัวอย่างบนอินเทอร์เน็ตจำนวนมากแปลงค่า MQ-135 เป็น CO2 ppm ค่านั้นเป็นการประมาณจากสมมติฐาน
ว่าแก๊สที่เปลี่ยนมีแต่ CO2 ซึ่งไม่จริงในห้องทั่วไป ถ้าต้องการวัด CO2 จริง ให้ใช้เซนเซอร์แบบ NDIR

## MQ-3 กับการวัดแอลกอฮอล์ในลมหายใจ

เป่าห่างจากตะแกรงราว 2–3 ซม. และรอให้ค่ากลับลงมาก่อนเป่าครั้งถัดไป ไอน้ำในลมหายใจทำให้ค่า
ขึ้นเล็กน้อยแม้ไม่ได้ดื่ม ผลที่ได้ใช้เป็นการสาธิตเท่านั้น ไม่ใช่การวัดตามกฎหมาย

## การติดตั้ง

- แก๊สหุงต้มหนักกว่าอากาศ ติด MQ-2 ใกล้พื้น
- CO ผสมกับอากาศได้ทั่ว ติด MQ-7 ที่ระดับหายใจ ราว 1–1.5 เมตร
- ตัวเซนเซอร์ร้อนขณะทำงาน อย่าติดในที่อับหรือใกล้วัสดุไวไฟ

## ปัญหาที่พบบ่อย

- **ค่าลอยลงเรื่อย ๆ ในชั่วโมงแรก** ปกติ รอให้นิ่งก่อนปรับเทียบ
- **บอร์ดรีสตาร์ตเมื่อต่อ MQ หลายตัว** ไส้ร้อนกินไฟรวมเกินกำลังขา 5V ใช้แหล่งจ่ายแยก
- **ค่าขึ้นตอนเปิดพัดลมหรือตอนฝนตก** ลมและความชื้นเปลี่ยนค่าได้ เป็นข้อจำกัดของเซนเซอร์ชนิดนี้
- **DO ไม่เปลี่ยนเลย** ตัวต้านทานปรับค่าบนบอร์ดตั้งไว้สุดทาง หมุนจนไฟ OUT บนบอร์ดเริ่มติด
