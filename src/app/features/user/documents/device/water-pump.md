## ภาพรวม

มอเตอร์กระแสตรงขนาดเล็กที่ปิดผนึกอยู่ในเรือนพลาสติก จุ่มลงในน้ำทั้งตัว น้ำเข้าทางช่องด้านล่าง
และออกทางหัวฉีด ต่อสายยางขนาด 5–8 มม. เข้าหัวฉีดเพื่อพาน้ำไปยังกระถาง

ปั๊มไม่มีขั้วบวกลบในแง่ความเสียหาย กลับขั้วแล้วมอเตอร์หมุนกลับทางและดูดน้ำได้น้อยลงมาก จึงควร
ต่อตามสีสาย

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| แรงดัน | รุ่น 3 V, 5 V หรือ 12 V (เลือกได้ในแผงด้านขวา) |
| กระแส | ราว 100–200 mA |
| อัตราไหล | ราว 80–120 ลิตรต่อชั่วโมง |
| ส่งน้ำได้สูง | ราว 40–110 ซม. |

ค่าจริงต่างกันมากตามยี่ห้อ ใช้ตารางนี้เป็นค่าคร่าว ๆ

## ห้ามต่อเข้าขา GPIO ตรง

ขา GPIO จ่ายกระแสได้ราว 20–40 mA ปั๊มต้องการ 100–200 mA ต่อตรงแล้วปั๊มไม่หมุนและขาอาจเสีย
ต้องสั่งผ่านรีเลย์หรือทรานซิสเตอร์ และควรใช้แหล่งจ่ายไฟแยก เช่น ถ่านหรืออะแดปเตอร์ 5 V

การต่อผ่านโมดูลรีเลย์:

| จาก | ไปที่ |
| --- | --- |
| ขั้วบวกของแหล่งจ่าย | `COM` ของรีเลย์ |
| `NO` ของรีเลย์ | สายแดงของปั๊ม |
| สายดำของปั๊ม | ขั้วลบของแหล่งจ่าย |
| ขา GPIO | `IN` ของรีเลย์ |

ใส่ไดโอด 1N4007 คร่อมขั้วปั๊มแบบกลับทาง (แถบสีไปทางสายแดง) และตัวเก็บประจุ 100 nF คร่อมขั้ว
ช่วยลดสัญญาณรบกวนที่ทำให้บอร์ดรีสตาร์ตเองเวลาปั๊มเริ่มหมุน

## รดน้ำตามความชื้นในดิน

```cpp
const int RELAY_PIN = 26;
const int SOIL_PIN = 34;
const int DRY_THRESHOLD = 2800;   // ปรับตามค่าที่วัดได้จริง

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, HIGH);  // โมดูลรีเลย์ส่วนใหญ่ทำงานเมื่อสั่ง LOW
}

void loop() {
  if (analogRead(SOIL_PIN) > DRY_THRESHOLD) {
    digitalWrite(RELAY_PIN, LOW);   // เปิดปั๊ม
    delay(3000);                    // รดน้ำ 3 วินาที
    digitalWrite(RELAY_PIN, HIGH);  // ปิดปั๊ม
    delay(60000);                   // รอให้น้ำซึมก่อนวัดใหม่
  }
  delay(1000);
}
```

การรอหลังรดน้ำสำคัญ ถ้าวัดทันที น้ำยังซึมไม่ถึงเซนเซอร์ โปรแกรมจะเปิดปั๊มซ้ำจนน้ำล้นกระถาง

## ห้ามเปิดตอนไม่มีน้ำ

น้ำช่วยระบายความร้อนและหล่อลื่นมอเตอร์ เปิดทิ้งไว้ในอากาศนานกว่าไม่กี่วินาทีจะทำให้ร้อนจนเสีย
งานที่ถังน้ำอาจแห้ง ควรมีเซนเซอร์วัดระดับน้ำหยุดปั๊มก่อน

## ปัญหาที่พบบ่อย

- **บอร์ดรีสตาร์ตทุกครั้งที่ปั๊มเริ่มหมุน** ใช้แหล่งจ่ายเดียวกับบอร์ด แยกแหล่งจ่ายและใส่ตัวเก็บประจุ
- **ปั๊มมีเสียงแต่น้ำไม่ออก** มีอากาศค้างในตัวปั๊ม จุ่มให้มิดแล้วเขย่าเบา ๆ
- **น้ำออกน้อย** ต่อกลับขั้ว หรือสายยางยาวและสูงเกินกำลังปั๊ม
- **ปั๊มไม่หมุนเลย** ต่อตรงจากขา GPIO หรือถ่านอ่อน
