## ภาพรวม

เซนเซอร์อุณหภูมิแบบแอนะล็อกที่ส่งแรงดันออกมาเป็นสัดส่วนตรงกับอุณหภูมิ **10 mV ต่อ 1 °C**
ปรับเทียบมาจากโรงงานแล้ว จึงไม่ต้องคำนวณอะไรนอกจากแปลงหน่วย

ต่างจาก DHT ตรงที่ให้ค่าต่อเนื่องและตอบสนองเร็ว แต่ไม่วัดความชื้นและมีสัญญาณรบกวนมากกว่า

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| ช่วงวัด | 0 ถึง 100 °C สำหรับรุ่น LM35DZ |
| ความคลาดเคลื่อน | ±0.5 °C ที่ 25 °C |
| อัตราส่วน | 10 mV ต่อ °C |
| แรงดันใช้งาน | 4–30 V |
| กระแส | ต่ำกว่า 60 µA |

ที่ 25 °C จะได้แรงดันออก 250 mV และที่ 100 °C ได้ 1.0 V

## ขาทั้งสาม

หันด้านแบนที่มีตัวหนังสือเข้าหาตัว ขาเรียงจากซ้ายไปขวาคือ **ไฟเลี้ยง สัญญาณออก กราวด์**

**สลับขาไฟเลี้ยงกับกราวด์จะทำให้ชิปร้อนจัดและพังภายในไม่กี่วินาที** ตรวจสองครั้งก่อนจ่ายไฟ
ถ้าจับแล้วร้อนผิดปกติให้ตัดไฟทันที

## แปลงค่าเป็นองศา

```cpp
const int LM35_PIN = 36;      // ต้องเป็นขา ADC1

float readCelsius() {
  int raw = analogRead(LM35_PIN);
  float volts = raw * 3.3 / 4095.0;
  return volts * 100.0;        // 10 mV ต่อ °C จึงคูณ 100
}
```

## ความละเอียดคือข้อจำกัดจริง

ADC ของ ESP32 มี 12 บิตบนช่วง 3.3 V ได้ความละเอียด `3.3 ÷ 4096 = 0.8` mV ต่อขั้น ซึ่ง
เท่ากับ 0.08 °C ฟังดูดี แต่สัญญาณรบกวนจริงสูงกว่านั้นหลายเท่า ค่าที่อ่านได้จึงกระโดดราว
±1 °C ถ้าไม่กรอง

```cpp
float readAveragedCelsius() {
  float total = 0;
  for (int i = 0; i < 32; i++) {
    total += readCelsius();
    delay(2);
  }
  return total / 32;
}
```

การเฉลี่ย 32 ครั้งลดการกระโดดลงเหลือราว ±0.2 °C ซึ่งใช้งานได้จริง

## ที่อุณหภูมิห้องใช้ช่วง ADC ได้น้อยมาก

ที่ 30 °C แรงดันออกคือ 300 mV จากช่วงทั้งหมด 3.3 V แปลว่าใช้ช่วงการวัดไปไม่ถึงหนึ่งในสิบ
ความละเอียดจึงเสียไปมาก งานที่ต้องการความแม่นยำสูงในช่วงอุณหภูมิห้องควรใช้เซนเซอร์ดิจิทัล
อย่าง DHT22 หรือ DS18B20 แทน

## สายยาวรับสัญญาณรบกวน

สัญญาณเป็นแรงดันระดับมิลลิโวลต์ สายที่ยาวเกินราวหนึ่งเมตรจะรับสัญญาณรบกวนจนค่าเพี้ยน
ถ้าจำเป็นต้องเดินสายยาว ให้ใส่ตัวเก็บประจุ 100 nF ระหว่างขาสัญญาณกับกราวด์ที่ปลายฝั่งบอร์ด

## ปัญหาที่พบบ่อย

- **ชิปร้อนจัด** ต่อไฟกลับขั้ว ตัดไฟทันที
- **ค่ากระโดดตลอด** ยังไม่ได้เฉลี่ยค่า
- **ค่าอ่านได้สูงกว่าความจริง** ตัวเซนเซอร์อยู่ใกล้ชิ้นส่วนที่ร้อน เช่น ตัวควบคุมแรงดัน
- **ค่าเพี้ยนเมื่อเปิด Wi-Fi** ต่อเข้าขา ADC2 ให้ย้ายไป ADC1
- **วัดต่ำกว่า 0 °C ไม่ได้** รุ่น LM35DZ วัดได้ตั้งแต่ 0 °C ขึ้นไปเท่านั้น
