## ภาพรวม

ใต้คันโยกมีตัวต้านทานปรับค่าได้ 10 kΩ สองตัว ตัวหนึ่งต่อกับแกนซ้ายขวา อีกตัวต่อกับแกนบนล่าง
แต่ละแกนเป็นตัวแบ่งแรงดันระหว่างไฟเลี้ยงกับกราวด์ ตอนปล่อยมือค่าจะอยู่กลางช่วง เอียงคันโยกแล้ว
ค่าจะเลื่อนไปทางไฟเลี้ยงหรือทางกราวด์

กดคันโยกลงจะเป็นการต่อขา `SW` ลงกราวด์ บนบอร์ดไม่มีตัวต้านทานดึงขึ้น

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| แรงดัน | 3.3–5 V |
| ความต้านทานแต่ละแกน | 10 kΩ |
| เอาต์พุต | แอนะล็อกสองแกน และสวิตช์หนึ่งตัว |

## จ่าย 3.3 V บน ESP32

ชื่อขาบนบอร์ดเขียนว่า `+5V` แต่ถ้าต่อกับ ESP32 ให้จ่าย **3.3 V** เพราะค่าแอนะล็อกออกมาเท่ากับ
ไฟเลี้ยง ถ้าจ่าย 5 V ตอนเอียงสุดจะได้ 5 V ซึ่งเกินช่วงของ ADC และทำให้ขาเสียได้ บน Arduino Uno
จ่าย 5 V ได้ตามปกติ

## อ่านค่า

```cpp
const int X_PIN = 34;    // ต้องเป็นขา ADC1
const int Y_PIN = 35;
const int SW_PIN = 25;
const int DEADZONE = 200;

int centreX = 0;
int centreY = 0;

void setup() {
  Serial.begin(115200);
  pinMode(SW_PIN, INPUT_PULLUP);
  centreX = analogRead(X_PIN);   // อ่านตอนปล่อยมือ
  centreY = analogRead(Y_PIN);
}

int axis(int pin, int centre) {
  int offset = analogRead(pin) - centre;
  return abs(offset) < DEADZONE ? 0 : offset;
}

void loop() {
  int x = axis(X_PIN, centreX);
  int y = axis(Y_PIN, centreY);
  bool pressed = digitalRead(SW_PIN) == LOW;
  Serial.printf("x=%d y=%d pressed=%d\n", x, y, pressed);
  delay(50);
}
```

## ต้องมีช่วงตาย

ตอนปล่อยมือ ค่าไม่ได้อยู่ตรงกลางพอดี และแกว่งเล็กน้อยตลอดเวลา ถ้าเอาค่าไปสั่งมอเตอร์ตรง ๆ หุ่นยนต์
จะคืบเองทั้งที่ไม่มีใครแตะ ให้อ่านค่ากลางตอนเริ่มโปรแกรม แล้วตัดค่าที่ใกล้ค่ากลางทิ้ง แบบ
`DEADZONE` ในโค้ดด้านบน

ADC ของ ESP32 ไม่เป็นเชิงเส้นช่วงใกล้ 0 V และใกล้ 3.3 V ค่าที่ปลายสุดของทั้งสองข้างจึงไม่เท่ากัน
งานที่ต้องการความละเอียดควรปรับเทียบค่าปลายทั้งสองข้างเองด้วย

## ปัญหาที่พบบ่อย

- **กดแล้วอ่านได้ HIGH ตลอด หรือค่าสุ่ม** ไม่ได้ตั้ง `INPUT_PULLUP` ที่ขา SW
- **แกน X กับ Y สลับกัน** ขึ้นกับการหันบอร์ด สลับในโค้ดได้เลย
- **ค่าตอนปล่อยมือไม่ใช่ครึ่งหนึ่งพอดี** ปกติ ใช้ค่ากลางที่อ่านตอนเริ่มโปรแกรม
- **ค่าไม่เปลี่ยนตามการเอียง** ต่อขาแอนะล็อกเข้าขา ADC2 ของ ESP32 ซึ่งใช้ไม่ได้ขณะเปิด Wi-Fi
