## ภาพรวม

ชิป DS18B20 ถูกหุ้มอยู่ในหลอดสแตนเลสปิดผนึก ต่อสายยาวออกมาสามเส้น ส่งค่าอุณหภูมิเป็นข้อมูล
ดิจิทัลผ่านบัสสายเดี่ยว (1-Wire) จึงไม่มีปัญหาแรงดันตกตามความยาวสายแบบเซนเซอร์แอนะล็อก

ทุกตัวมีหมายเลขประจำตัว 64 บิตจากโรงงาน ต่อหลายตัวบนสายข้อมูลเส้นเดียวกันได้ ใช้ขา GPIO
แค่ขาเดียวสำหรับเซนเซอร์หลายจุด

| สาย | หน้าที่ |
| --- | --- |
| แดง | VCC |
| เหลือง | DATA |
| ดำ | GND |

บางยี่ห้อใช้สีต่างจากนี้ ตรวจกับเอกสารของผู้ขายก่อนต่อ

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| แรงดัน | 3.0–5.5 V |
| ช่วงวัด | −55 ถึง 125 °C |
| ความแม่นยำ | ±0.5 °C ในช่วง −10 ถึง 85 °C |
| ความละเอียด | 9–12 บิต |
| เวลาแปลงค่าที่ 12 บิต | สูงสุด 750 ms |

## ต้องมีตัวต้านทานดึงขึ้น

สาย DATA ต้องมีตัวต้านทาน **4.7 kΩ** ต่อจาก DATA ไปที่ VCC ตัวเดียวใช้ร่วมกันได้ทั้งบัส ไม่ต้องใส่
ต่อเซนเซอร์หนึ่งตัว ถ้าสายยาวหลายสิบเมตรแล้วอ่านค่าไม่ติด ให้ลดค่าลงเป็น 2.2 kΩ

## อ่านค่า

ใช้ไลบรารี OneWire และ DallasTemperature

```cpp
#include <OneWire.h>
#include <DallasTemperature.h>

const int ONE_WIRE_PIN = 4;
OneWire oneWire(ONE_WIRE_PIN);
DallasTemperature sensors(&oneWire);

void setup() {
  Serial.begin(115200);
  sensors.begin();
}

void loop() {
  sensors.requestTemperatures();
  float celsius = sensors.getTempCByIndex(0);
  if (celsius == DEVICE_DISCONNECTED_C) {
    Serial.println("อ่านเซนเซอร์ไม่ได้");
  } else {
    Serial.println(celsius);
  }
  delay(1000);
}
```

เครื่องจำลองบนแคนวาสของระบบนี้ยังรันไลบรารีไม่ได้ จะแจ้งว่าคำสั่งไม่รองรับ โค้ดด้านบนใช้กับ
บอร์ดจริง

ถ้าต่อหลายตัว ใช้ `getTempCByIndex(1)`, `getTempCByIndex(2)` ไปเรื่อย ๆ แต่ลำดับขึ้นกับหมายเลข
ประจำตัว ไม่ใช่ลำดับที่ต่อสาย งานที่ต้องรู้ว่าตัวไหนอยู่ตรงไหน ให้อ่านหมายเลขของแต่ละตัวเก็บไว้
แล้วอ่านค่าตามหมายเลข

## การติดตั้ง

หัววัดกันน้ำได้ แต่ **รอยต่อระหว่างสายกับหลอด** เป็นจุดที่น้ำซึมเข้าได้ถ้าจุ่มลึกนาน ๆ หรือโดนน้ำร้อน
ซ้ำ ๆ อย่าจุ่มให้ท่อหดที่รอยต่อจมน้ำ

สายเป็นพลาสติก PVC ไม่ทนความร้อน ถ้าวัดของที่ร้อนเกิน 80 °C ให้ใช้รุ่นที่สายเป็นซิลิโคน

## ปัญหาที่พบบ่อย

- **อ่านได้ −127 °C** สื่อสารกับเซนเซอร์ไม่ได้ ลืมตัวต้านทานดึงขึ้น สายหลวม หรือต่อผิดสี
- **อ่านได้ 85 °C ตลอด** เป็นค่าเริ่มต้นของชิปหลังเปิดไฟ แปลว่าไฟเลี้ยงไม่พอหรือไฟกระตุก
- **อ่านได้บางครั้ง ไม่ได้บางครั้ง** สายยาวเกินไปกับค่าตัวต้านทาน ลองลดเป็น 2.2 kΩ
- **ต่อหลายตัวแล้วลำดับสลับกัน** ลำดับมาจากหมายเลขประจำตัว ให้อ่านตามหมายเลขแทนลำดับ
