## ภาพรวม

สวิตช์ที่ค้างตำแหน่งไว้ ต่างจากปุ่มกดตรงที่ไม่ดีดกลับเมื่อปล่อยมือ ใช้กับค่าที่ตั้งแล้วอยู่อย่างนั้น
เช่น เปิดปิดเครื่อง เลือกโหมด หรือตั้งแอดเดรสอุปกรณ์

## แบบที่ระบบรองรับ

| แบบ | จำนวนตำแหน่ง | ใช้กับ |
| --- | --- | --- |
| สวิตช์เลื่อน SPDT | 2 ทาง | เปิดปิดเครื่อง สลับแหล่งจ่ายไฟ |
| ดิปสวิตช์ 2 ตัว | เปิดปิด 2 ชุด | เลือกโหมดตอนติดตั้ง |
| ดิปสวิตช์ 4 ตัว | เปิดปิด 4 ชุด | ตั้งแอดเดรสหรือตัวเลือกการบูต |
| ดิปสวิตช์ 8 ตัว | เปิดปิด 8 ชุด | ตั้งค่าเป็นเลขฐานสอง 8 บิต |

## สวิตช์เลื่อน SPDT

มีสามขา ขากลางคือขาร่วมที่ต่อกับขาริมด้านใดด้านหนึ่งตามตำแหน่งของก้าน ใช้ตัดต่อวงจรเดียว
โดยต่อแค่ขากลางกับขาริมหนึ่งข้าง หรือใช้สลับระหว่างสองทางโดยต่อครบสามขา

## ดิปสวิตช์

แต่ละตัวเป็นสวิตช์แยกอิสระ ขาที่อยู่ตรงข้ามกันคือคู่ของสวิตช์ตัวเดียวกัน ตัวเลขพิมพ์บนตัวถังบอก
ลำดับ และมักมีคำว่า `ON` พิมพ์ไว้ที่ด้านที่เลื่อนไปแล้วต่อวงจร

ทุกตัวต้องมีตัวต้านทานพูลอัปเหมือนปุ่มกด วิธีที่ง่ายที่สุดคือใช้พูลอัปในตัวชิป

```cpp
const int DIP_PINS[4] = {32, 33, 25, 26};

void setup() {
  for (int pin : DIP_PINS) {
    pinMode(pin, INPUT_PULLUP);
  }
}

// อ่านทั้งชุดเป็นเลขฐานสอง สวิตช์ที่เลื่อนไป ON จะให้ค่า LOW
int readDipValue() {
  int value = 0;
  for (int i = 0; i < 4; i++) {
    if (digitalRead(DIP_PINS[i]) == LOW) {
      value |= (1 << i);
    }
  }
  return value;
}
```

ดิปสวิตช์ 4 ตัวให้ค่า 0–15 และ 8 ตัวให้ 0–255

## อ่านครั้งเดียวตอนบูตก็พอ

ดิปสวิตช์เป็นค่าที่ตั้งไว้ตอนติดตั้งแล้วไม่แตะอีก การอ่านทุกรอบของ `loop()` เปลืองเวลาโดยไม่ได้
อะไร อ่านครั้งเดียวใน `setup()` แล้วเก็บไว้ในตัวแปร

ข้อยกเว้นคือถ้าต้องการให้เปลี่ยนค่าได้โดยไม่รีสตาร์ต ซึ่งกรณีนั้นควรอ่านทุกหนึ่งวินาทีก็เพียงพอ

## กินขาเยอะ

ดิปสวิตช์ 8 ตัวกินขา GPIO แปดขา ซึ่งมากเมื่อเทียบกับสิ่งที่ได้ ถ้าขาไม่พอ ให้ต่อผ่านตัวต้านทาน
เป็นเครือข่ายแบ่งแรงดันแล้วอ่านด้วยขา ADC ขาเดียว หรือใช้ชิฟต์รีจิสเตอร์แบบอ่านเข้า

## ปัญหาที่พบบ่อย

- **อ่านค่าได้สุ่ม** ลืมตัวต้านทานพูลอัป
- **ตรรกะกลับด้านจากที่คาด** พูลอัปทำให้ `ON` เป็น `LOW` ไม่ใช่ `HIGH`
- **สวิตช์บางตัวไม่ตอบสนอง** ต่อผิดคู่ขา ใช้ขาที่อยู่ตรงข้ามกัน
- **ค่าเปลี่ยนเองเมื่อจับตัวบอร์ด** สายยาวเกินไปทำให้รับสัญญาณรบกวน ใช้พูลอัปภายนอกค่า
  ต่ำลงเช่น 4.7 kΩ
