## ภาพรวม

โมดูลสัมผัสแบบเก็บประจุที่ใช้ชิป TTP223 ตรวจจับการเปลี่ยนแปลงของความจุไฟฟ้าเมื่อนิ้วเข้าใกล้
แผ่นรับสัมผัส ไม่มีชิ้นส่วนที่เคลื่อนไหวจึงไม่สึกและไม่มีปัญหาหน้าสัมผัสสั่นเหมือนปุ่มกด

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| แรงดัน | 2–5.5 V |
| กระแส | ต่ำกว่า 10 µA ขณะรอ |
| เวลาตอบสนอง | ราว 60 มิลลิวินาที |
| สัญญาณออก | ดิจิทัล สูงเมื่อสัมผัส |

## สามขา

`VCC`, `GND`, และ `I/O` ต่อ `I/O` เข้าขา GPIO ได้ตรง ไม่ต้องมีตัวต้านทานพูลอัป เพราะโมดูล
ขับสัญญาณออกมาเองทั้งสองสถานะ

สัญญาณเป็น `HIGH` เมื่อสัมผัส ซึ่งตรงกับสัญชาตญาณ ต่างจากโมดูลเซนเซอร์อื่นหลายตัวที่กลับด้าน

```cpp
const int TOUCH_PIN = 15;

void setup() {
  pinMode(TOUCH_PIN, INPUT);
}

bool isTouched() {
  return digitalRead(TOUCH_PIN) == HIGH;
}
```

## ทำงานผ่านวัสดุที่ไม่นำไฟฟ้าได้

นี่คือข้อได้เปรียบหลัก โมดูลตรวจจับได้ผ่านพลาสติก อะคริลิก กระจก หรือไม้ที่หนาไม่เกินราว
3 มิลลิเมตร ทำให้ติดไว้หลังแผงหน้าปัดได้โดยไม่ต้องเจาะรู แผงจึงกันน้ำและกันฝุ่นได้สนิท

**ทะลุโลหะไม่ได้** โลหะบังสนามไฟฟ้าทั้งหมด

วัสดุยิ่งหนาความไวยิ่งลด ถ้าติดหลังแผ่นหนาต้องเพิ่มขนาดแผ่นรับสัมผัสหรือปรับความไวที่ชิป

## สองโหมดที่เลือกได้จากจุดบัดกรี

บนบอร์ดมีจุดบัดกรีสองจุดชื่อ `A` และ `B` ที่เปลี่ยนพฤติกรรม

| จุด | ผล |
| --- | --- |
| ไม่บัดกรีทั้งคู่ | ค่าปกติ สัญญาณสูงเฉพาะขณะสัมผัส |
| บัดกรี `B` | โหมดสลับ แตะครั้งหนึ่งเปิด อีกครั้งปิด |
| บัดกรี `A` | กลับตรรกะสัญญาณออก |

โหมดสลับสะดวกสำหรับสวิตช์ไฟ เพราะไม่ต้องเขียนโค้ดจับสถานะเอง

## ความไวเปลี่ยนตามสภาพแวดล้อม

ชิปปรับค่าพื้นฐานอัตโนมัติเมื่อจ่ายไฟ ถ้ามีนิ้วแตะอยู่ตอนบูต ชิปจะถือว่านั่นคือสถานะปกติ แล้ว
ตรวจจับผิดไปทั้งหมด อย่าแตะแผ่นรับสัมผัสตอนเปิดเครื่อง

ความชื้นสูงและน้ำที่เกาะบนแผ่นก็ทำให้ไวเกินจนตรวจจับเองได้

## ปัญหาที่พบบ่อย

- **ตรวจจับเองตลอดเวลา** มีนิ้วแตะอยู่ตอนจ่ายไฟ ให้ตัดไฟแล้วเปิดใหม่โดยไม่แตะ
- **ไม่ตอบสนองเลย** วัสดุที่คั่นหนาเกินไป หรือเป็นโลหะ
- **ตอบสนองช้า** ปกติของชิปนี้ ราว 60 มิลลิวินาที ไม่เหมาะกับงานที่ต้องกดรัว
- **ทำงานเองเมื่อมีมอเตอร์ทำงานใกล้ ๆ** สัญญาณรบกวน ให้เดินสายแยกจากสายมอเตอร์
