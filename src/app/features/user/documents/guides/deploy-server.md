การบันทึกโค้ด การคอมไพล์ และการเขียนลงบอร์ดเป็นคนละขั้นตอน
บทนี้ใช้เมื่อพร้อมทดสอบฮาร์ดแวร์จริง

## เข้าใจคำสั่งก่อนเริ่ม

| คำสั่ง | ใช้ตรวจอะไร |
| --- | --- |
| Save | บันทึกไฟล์ไปยังเวิร์กสเปซ |
| Compile | ส่งไฟล์ที่บันทึกแล้วไปคอมไพล์บนเซิร์ฟเวอร์ และอ่านผลจาก Compile output |
| Upload | Compile แล้วเขียนเฟิร์มแวร์ลงบอร์ดที่เสียบกับเครื่องของคุณผ่านเบราว์เซอร์ |
| Serial Monitor | อ่านข้อความจากบอร์ดจริงผ่านพอร์ต USB ของเครื่องคุณ |
| Start ใน Virtual Device | รันในตัวจำลองของหน้าเว็บ |

**Deploy** ใน IDE และ **Publish** ใน Dashboard ปัจจุบันยังเป็นสถานะแสดงผลของหน้า
ไม่ใช่หลักฐานว่ามีการเผยแพร่เว็บหรือบริการสาธารณะสำเร็จ และ Upload ไม่ได้เผยแพร่ Dashboard ให้โดยอัตโนมัติ

## 1. ตรวจความพร้อม

1. ใช้ **Chrome** หรือ **Edge** บนคอมพิวเตอร์ เบราว์เซอร์อื่นและมือถือยังไม่รองรับ Web Serial
2. เลือกโปรเจกต์และบอร์ดให้ตรงกับบอร์ดที่จะใช้
3. ตรวจไฟล์หลัก: PlatformIO ใช้ไฟล์ใน `src/` `include/` และ `lib/` ส่วน Arduino C++ ใช้ `main.ino` และไฟล์ข้างกัน
4. เสียบบอร์ดเข้ากับเครื่องที่เปิดเบราว์เซอร์ด้วยสาย USB ที่รับส่งข้อมูลได้ (ไม่ใช่สายชาร์จอย่างเดียว)

บอร์ดที่ Compile และ Upload ได้ตอนนี้: ESP32 DevKit V1, ESP32 DevKit 38 ขา, ESP32-WROOM-32,
ESP32-CAM, Arduino Uno และ Arduino Nano ส่วน Arduino Mega 2560 Compile ได้
แต่ระบบจะดาวน์โหลดไฟล์ `firmware.hex` ให้แทนการเขียนลงบอร์ด
ESP32-S3, ESP8266 และ MicroPython ยังไม่รองรับ

## 2. สั่ง Compile ก่อน

กด **Compile** แล้วเปิด **Compile output** รอจนได้ผลสำเร็จหรือข้อผิดพลาด
ระบบบันทึกไฟล์ก่อนเริ่ม แล้วคอมไพล์สิ่งที่บันทึกไว้ ไม่ใช่สิ่งที่ยังพิมพ์ค้างอยู่
ถ้าโค้ดไม่เปลี่ยนจาก Compile ที่สำเร็จครั้งก่อน ระบบจะใช้ผลเดิมทันทีโดยไม่นับเวลา Compile

ถ้าคอมไพล์ล้มเหลว ให้ดูข้อผิดพลาดแรกที่ระบุชื่อไฟล์และเลขบรรทัด
การ Compile ผ่านช่วยยืนยันว่าคอมไพล์ได้ แต่ยังไม่ได้ยืนยันว่าวงจรทำงาน

ไฟล์ `platformio.ini` ของโปรเจกต์ไม่ถูกใช้ตอน Compile ระบบสร้างค่าตั้งเองตามบอร์ด
ไลบรารีที่ใช้ได้คือไลบรารีของ ESP32/Arduino และไลบรารีของอุปกรณ์ในแคตตาล็อก
หรือไลบรารีที่วางไว้เองในโฟลเดอร์ `lib/`

## 3. เลือกอุปกรณ์จริงและพอร์ต

1. เปลี่ยนเป้าหมายเป็น **อุปกรณ์จริง**
2. เปิดรายการอุปกรณ์แล้วเลือก **เพิ่มอุปกรณ์…**
3. เบราว์เซอร์จะถามว่าให้หน้าเว็บใช้พอร์ตไหน เลือกพอร์ตของบอร์ด
   (มักแสดงเป็น CP210x, CH340 หรือ USB Serial) แล้วกด Connect

ครั้งต่อไปพอร์ตที่อนุญาตแล้วจะอยู่ในรายการเอง
หากมีหลายบอร์ด ให้ถอดบอร์ดอื่นออกตอนเพิ่มอุปกรณ์ เพื่อให้รู้แน่ว่าพอร์ตไหนคือบอร์ดไหน

- แต่ละโปรเจกต์จำบอร์ดที่เลือกล่าสุดไว้ เปิดโปรเจกต์อีกครั้งระบบจะเลือกบอร์ดนั้นให้ถ้าเสียบอยู่
- ถ้าถอดสาย รายการจะแสดง **ถอดออกแล้ว** และสถานะเป็น Disconnected เสียบกลับแล้วระบบเชื่อมต่อให้เอง
- เลือก **ค้นหาอุปกรณ์อีกครั้ง** เพื่ออ่านรายการพอร์ตใหม่โดยไม่ต้องรีเฟรชหน้า
- เบราว์เซอร์ไม่บอกชื่อ COM หรือ /dev ให้หน้าเว็บ รายการจึงแสดงชนิดชิป USB และรหัส VID:PID
  ส่วนชื่อ COM จะเห็นในหน้าต่างเลือกพอร์ตของเบราว์เซอร์ตอนเพิ่มอุปกรณ์
- หน้าเว็บมองเห็นเฉพาะพอร์ตที่คุณเคยอนุญาตแล้วเท่านั้น พอร์ตใหม่ต้องเพิ่มผ่าน **เพิ่มอุปกรณ์…** เสมอ

## 4. อัปโหลด

กด **Upload** ระบบจะ Compile (หรือใช้ผลเดิม) ดาวน์โหลดเฟิร์มแวร์ แล้วเขียนลงบอร์ด
ปุ่มแสดงความคืบหน้าเป็นเปอร์เซ็นต์ และ Compile output แสดงแต่ละขั้น

- ถ้า Serial Monitor ของ IDE เปิดอยู่ ระบบจะปิดก่อนเขียน แล้วเปิดกลับให้หลังเขียนเสร็จ
- โปรแกรมอื่นที่เปิดพอร์ตเดียวกันอยู่ (เช่น Arduino IDE) ต้องปิดเอง
- ESP32 บางรุ่นต้องกดปุ่ม **BOOT** ค้างไว้ตอนเริ่มเชื่อมต่อ ถ้าขึ้นว่าเชื่อมต่อ bootloader ไม่ได้
- ระบบตรวจชนิดชิปก่อนเขียน ถ้าเสียบบอร์ดผิดรุ่น จะหยุดโดยไม่เขียนอะไรลงบอร์ด

## 5. ตรวจผลบนบอร์ด

1. หลัง Upload สำเร็จ เปิด **Serial Monitor**
2. ตั้ง baud rate ให้ตรงกับ `Serial.begin(...)` ในโค้ด เช่น `115200` สำหรับบทเริ่มต้น
3. กด **Monitor** เพื่อเชื่อมต่อ
4. ตรวจข้อความหรือค่าตามที่คาด
5. ใช้ **Clear** เมื่อต้องการเริ่มอ่านรอบใหม่ หรือส่งออก log เพื่อเก็บผล
6. กด **Disconnect** เมื่อเลิกใช้พอร์ต

## แยกอาการเพื่อแก้ให้ตรงจุด

| อาการ | จุดที่ควรตรวจ |
| --- | --- |
| Compile ยังไม่เริ่ม | ไฟล์บันทึกสำเร็จหรือไม่ และระบบแจ้งว่าเปิดบริการ Compile แล้วหรือยัง |
| รอ compile worker นาน | งานอยู่ในคิว ระบบจะยกเลิกเองถ้ารอเกิน 15 นาที |
| Compile error | โค้ด และไลบรารีที่ข้อความระบุ |
| ไม่มีพอร์ตให้เลือก | ใช้ Chrome/Edge สาย USB รับส่งข้อมูลได้ และไดรเวอร์ CP210x/CH340 บนเครื่อง |
| เปิดพอร์ตไม่ได้ | โปรแกรมหรือแท็บอื่นที่ใช้พอร์ตเดียวกัน |
| เชื่อมต่อ bootloader ไม่ได้ | กด BOOT ค้าง (ESP32) หรือลองเสียบใหม่ แล้ว Upload อีกครั้ง |
| Upload ผ่านแต่ไม่มีข้อความ | baud rate โค้ดพิมพ์ข้อความ และสถานะ Monitor |

ขั้นตอนนี้สำเร็จเมื่อมีผล Upload สำเร็จและตรวจพฤติกรรมที่คาดจากบอร์ดได้จริง
เก็บโค้ดที่ทดสอบผ่านและ log สำคัญไว้ก่อนเพิ่มฟีเจอร์ถัดไป
