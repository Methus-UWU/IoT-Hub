IDE เป็นพื้นที่แก้โค้ดของโปรเจกต์ ใช้ร่วมกับ Virtual Device และผู้ช่วย AI ได้
เป้าหมายของบทนี้คือแก้ไฟล์ บันทึกอย่างมั่นใจ และรู้ว่าจะดูผลการทำงานที่ไหน

## รู้จักพื้นที่ทำงาน

| ส่วน | หน้าที่ |
| --- | --- |
| แท็บไฟล์ | เลือกไฟล์ที่กำลังแก้ไข |
| ตัวแก้ไขโค้ด | เขียนซอร์สและดูตำแหน่งข้อผิดพลาด |
| Save | บันทึกไฟล์ที่เปิดอยู่ |
| Compile output | อ่านผลคอมไพล์และข้อความผิดพลาดจากงาน Compile/Upload |
| Serial Monitor | อ่านข้อความจากอุปกรณ์จริงที่เลือกพอร์ตไว้ |
| ผู้ช่วย AI | ถามเกี่ยวกับงานและตรวจแผนเปลี่ยนแปลง |

## 1. เปิดไฟล์หลักให้ถูก

โปรเจกต์ PlatformIO ใช้ `src/main.cpp` ส่วน Arduino C++ ใช้ `main.ino`
งานเก่าอาจมีชื่อไฟล์ต่างออกไป ให้ตรวจไฟล์ที่มีอยู่ก่อนเพิ่มไฟล์ใหม่

เปิดทีละไฟล์และสังเกตชื่อที่แท็บ รวมถึงชื่อไฟล์ที่ผู้ช่วย AI แสดงว่าใช้งานอยู่
การเปิดไฟล์ตั้งค่าแทนไฟล์โค้ดอาจทำให้คำถามอย่าง “แก้ไฟล์นี้” มีความหมายต่างจากที่ตั้งใจ

## 2. แก้และบันทึก

1. แก้ข้อความในตัวแก้ไขโค้ด
2. สังเกตสถานะ **Unsaved** ระหว่างที่ยังมีการเปลี่ยนแปลง
3. กด **Save** หรือ `Ctrl+S` เพื่อสั่งบันทึกทันที
4. รอข้อความ **Saved to workspace** หรือ **Auto-saved to workspace**
5. เมื่อบันทึกสำเร็จแล้ว ลองเปิดไฟล์ซ้ำเพื่อตรวจเนื้อหา

ระบบมีการบันทึกอัตโนมัติหลังหยุดพิมพ์ แต่ควรตรวจข้อความสถานะก่อนเปลี่ยนหน้า
โดยเฉพาะก่อนเริ่มจำลองหรือขอให้ AI แก้ไฟล์

### ถ้าบันทึกได้เฉพาะในเบราว์เซอร์

สำเนาในเบราว์เซอร์ช่วยเก็บงานระหว่างการเชื่อมต่อมีปัญหา แต่ยังไม่ยืนยันว่าไฟล์บนระบบอัปเดตแล้ว
คัดลอกโค้ดไปเก็บในไฟล์ส่วนตัว แล้วลองบันทึกใหม่เมื่อเชื่อมต่อได้

หากเปิดโปรเจกต์เดียวกันหลายแท็บและพบข้อขัดแย้ง ให้สำรองเนื้อหาที่แก้ก่อนโหลดใหม่
จากนั้นเทียบกับฉบับล่าสุด หลีกเลี่ยงการสลับกดบันทึกจากหลายแท็บ

## 3. เพิ่มและลบไฟล์

ใช้ **New File** เมื่อต้องแยกโค้ดหรือเพิ่มไฟล์ใหม่ ตั้งชื่อและนามสกุลตามหน้าที่
สำหรับการลบ ให้กดปุ่มลบของไฟล์ อ่านชื่อในหน้าต่างยืนยันก่อนดำเนินการ
โปรเจกต์ต้องเหลืออย่างน้อยหนึ่งไฟล์

การลบไฟล์หลักหรือไฟล์ตั้งค่าอาจทำให้ Compile ไม่ได้ แม้ยังเหลือไฟล์อื่นในโปรเจกต์
เก็บสำเนาก่อนลบไฟล์ที่ไม่แน่ใจว่าถูกใช้งานหรือไม่

### เขียนโค้ดหลายไฟล์

จัดไฟล์ได้แบบเดียวกับ Arduino IDE และ PlatformIO ทั้งตอน Compile และใน Simulator

| แบบ | ไฟล์ |
| --- | --- |
| Arduino IDE | `main.ino` เป็นไฟล์หลัก แท็บ `.ino` อื่นต่อท้ายตามลำดับตัวอักษร และ `.cpp`/`.h` วางข้างกัน |
| PlatformIO | `src/main.cpp` กับไฟล์อื่นใน `src/` ส่วน header ไว้ใน `include/` |
| ไลบรารีของโปรเจกต์ | `lib/<ชื่อ>/src/<ชื่อ>.h` และ `.cpp` ใช้ด้วย `#include <ชื่อ.h>` |

- ประกาศฟังก์ชันไว้ใน `.h` แล้วเขียนตัวฟังก์ชันใน `.cpp` ได้ ตัวแปรที่ใช้ร่วมกันประกาศ `extern` ใน `.h`
- ไลบรารีใน `lib/` ถูกใช้เฉพาะเมื่อมีไฟล์ไหน `#include` มัน
- ไลบรารีมาตรฐานที่ติดตั้งให้แล้ว (เช่น DHT, Servo, SSD1306, LiquidCrystal_I2C, DallasTemperature)
  ใช้ `#include` ได้ทันทีเหมือน Arduino IDE
- ถ้าโค้ดผิด Simulator จะบอกชื่อไฟล์และบรรทัดในไฟล์นั้น

### ติดตั้งไลบรารีด้วย Library Manager

เปิดเมนู `⋯` ใน IDE แล้วเลือก **Libraries**

1. แท็บ **Browse** ค้นหาจาก PlatformIO Registry ระบบแสดงเฉพาะไลบรารีที่ใช้กับบอร์ดของโปรเจกต์ได้
   เปลี่ยนการเรียงเป็น **Recently updated** หรือ **Trending** เพื่อหาไลบรารีใหม่ๆ
2. กด **Install** เพื่อติดตั้งเวอร์ชันล่าสุด หรือกด **Versions** เพื่อเลือกเวอร์ชันเอง
   ไลบรารีที่ต้องใช้ร่วมกันจะถูกติดตั้งให้ด้วย
3. แท็บ **Installed** ใช้เปลี่ยนเวอร์ชันหรือลบไลบรารี

ไลบรารีที่ติดตั้งแล้วอยู่ใน `lib/<ชื่อ>/` ใช้ `#include` ได้ทันทีตอน Compile
ไฟล์เหล่านี้ไม่แสดงเป็นแท็บในตัวแก้ไข และนับรวมในโควตาโปรเจกต์ (500 ไฟล์ / 8 MB)
Simulator ในเบราว์เซอร์ยังรันได้เฉพาะไลบรารีที่ระบบจำลองไว้

## 4. เลือกว่าจะทดสอบที่ไหน

- **อุปกรณ์จำลอง:** เปิด Simulator หรือ Virtual Device แล้วใช้ Start และ Serial monitor ของหน้านั้น
- **อุปกรณ์จริง:** เพิ่มพอร์ต USB ผ่านเบราว์เซอร์ (Chrome/Edge) ทำ Compile/Upload และใช้ Serial Monitor ของ IDE

ผลจาก Serial monitor ในหน้าจำลองกับอุปกรณ์จริงเป็นคนละแหล่งข้อมูล
ถ้าไม่เห็นข้อความ ให้ตรวจว่ากำลังดูหน้าต่างของเป้าหมายที่ใช้อยู่

## 5. อ่านข้อผิดพลาดโดยเริ่มจากจุดแรก

เมื่อ Compile ล้มเหลว ให้ดูชื่อไฟล์และเลขบรรทัดของข้อผิดพลาดแรก แก้จุดนั้นก่อน
แล้วค่อยสั่งใหม่ เพราะข้อผิดพลาดหนึ่งจุดอาจทำให้เกิดข้อความตามมาอีกหลายบรรทัด

ถ้าแจ้งว่าบันทึกไฟล์ไม่ได้หรือติดต่อระบบไม่ได้ งาน Compile อาจยังไม่เริ่ม
ให้แก้การบันทึกก่อนแก้โค้ด

## สำรองงานให้ครบ

คำสั่ง Export ใน IDE ปัจจุบันส่งออกข้อความของไฟล์ที่กำลังเปิดพร้อมข้อมูลโปรเจกต์
จึงไม่ใช่ไฟล์สำรองทั้งโปรเจกต์ หากมีหลายไฟล์ให้เก็บแต่ละไฟล์ที่ต้องการแยกกัน
รวมทั้ง `platformio.ini` เมื่อใช้งาน PlatformIO
