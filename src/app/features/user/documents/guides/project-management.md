บทนี้พาสร้างโปรเจกต์จนเปิดพื้นที่ทำงานได้ รวมถึงค้นหางานเดิมและลบงานที่ไม่ต้องการ
ก่อนเริ่มให้เข้าสู่ระบบและอยู่ในเวิร์กสเปซที่ต้องการเก็บงาน

## 1. ตั้งชื่อให้ค้นหาง่าย

เปิดหน้า **โปรเจกต์** แล้วกดสร้างโปรเจกต์ใหม่ กรอกชื่อที่บอกหน้าที่ของงาน เช่น
“Greenhouse temperature monitor” แทนชื่อที่แยกไม่ออกอย่าง “Test 1”

ถ้ามีช่องคำอธิบาย ให้ระบุผลที่คาดหวัง อุปกรณ์ และเงื่อนไขการทำงาน เช่น
“อ่านอุณหภูมิจาก DHT22 และแสดงข้อความผ่าน Serial ทุกสองวินาที”

## 2. เลือกรูปแบบเริ่มต้น

### ตั้งค่าเอง

1. เลือก **ตั้งค่าเอง**
2. เลือกบอร์ดจากรายการที่โหลดสำเร็จแล้ว
3. ค้นหาอุปกรณ์เสริมและทำเครื่องหมายรายการที่ต้องการ
4. ใช้ปุ่มเพิ่มหรือลดจำนวนสำหรับอุปกรณ์ชนิดเดียวกันหลายชิ้น
5. ตรวจจำนวนรวมก่อนสร้าง บอร์ดถูกเพิ่มให้อยู่แล้ว

เริ่มด้วยบอร์ดอย่างเดียวได้ การเลือกอุปกรณ์ไว้ล่วงหน้าไม่ได้แปลว่าสายทุกเส้นต่อให้แล้ว
หลังสร้างให้ตรวจวงจรใน Virtual Device

### เริ่มต้นกับ AI

1. เลือก **เริ่มต้นกับ AI**
2. เลือกบอร์ดและเขียนคำอธิบายงานให้ชัด
3. สร้างโปรเจกต์ แล้วรอผู้ช่วยใน IDE เสนอแผน
4. ตรวจรายการอุปกรณ์ สาย และไฟล์ก่อนยอมรับ

หากไม่ได้เขียนคำอธิบาย ระบบจะไม่สร้างแผนให้อัตโนมัติ ให้พิมพ์คำขอในผู้ช่วยภายหลัง
การรีโหลดหน้าไม่ใช่คำสั่งให้สร้างแผนเดิมซ้ำ

## 3. เลือกเฟรมเวิร์กและตรวจไฟล์เริ่มต้น

ตัวเลือกขึ้นกับบอร์ดที่เลือก ตรวจชื่อไฟล์จริงใน IDE ก่อนเริ่มเขียน:

| ตัวเลือก | ไฟล์เริ่มต้นที่ควรมองหา |
| --- | --- |
| PlatformIO | `platformio.ini` และ `src/main.cpp` |
| Arduino C++ | `main.ino` |

สำหรับ PlatformIO ให้เก็บ `#include <Arduino.h>` ในไฟล์ C++ ไว้
ไม่จำเป็นต้องสร้าง `main.ino` เพิ่มถ้ามี `src/main.cpp` เป็นไฟล์หลักอยู่แล้ว

## 4. กลับมาเปิดงานเดิม

1. กลับหน้าโปรเจกต์และค้นหาชื่อ
2. เปลี่ยนมุมมองตารางหรือรายการตามถนัด และใช้ตัวเลือกเรียงลำดับ
3. เปิดเมนูของการ์ดเพื่อเข้า IDE หรือ Virtual Device
4. ตรวจชื่อโปรเจกต์อีกครั้งก่อนแก้ไข โดยเฉพาะเมื่อเปิดหลายแท็บ

## 5. ลบโปรเจกต์

การลบเป็นการลบถาวร ให้สำรองไฟล์ที่ต้องใช้ก่อน เปิดเมนูของการ์ด เลือกลบ
อ่านชื่อในหน้าต่างยืนยัน แล้วจึงยืนยัน เจ้าของหรือผู้ดูแลเวิร์กสเปซเป็นผู้มีสิทธิ์ลบ

เมื่อลบสำเร็จ การ์ดต้องหายจากรายการ หากเกิดข้อผิดพลาด การ์ดยังคงอยู่เพื่อให้ลองใหม่
อย่าถือว่าการปิดหน้าต่างยืนยันเท่ากับลบสำเร็จ

## เมื่อสร้างไม่ได้

| อาการ | วิธีตรวจ |
| --- | --- |
| รายการบอร์ดไม่มา | กดลองโหลดรายการอีกครั้งและตรวจการเชื่อมต่อ |
| ชื่อไม่ผ่าน | อ่านข้อความใต้ช่องและแก้ตามที่ระบุ |
| เกินโควตา | ลดจำนวนอุปกรณ์หรือตรวจการใช้งานของเวิร์กสเปซ |
| ไม่มีสิทธิ์ | ตรวจบัญชีและเวิร์กสเปซที่กำลังใช้งาน |
| AI ไม่เริ่ม | ตรวจว่ามีคำอธิบาย หรือส่งคำขอจาก IDE โดยตรง |

หลังสร้างสำเร็จ ลองกลับรายการแล้วเปิดงานอีกครั้งเพื่อยืนยันว่าโปรเจกต์ถูกบันทึก
