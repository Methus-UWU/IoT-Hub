บทนี้พาสร้างโปรเจกต์ ESP32 บันทึกโค้ด และดูข้อความใน Serial monitor ของหน้าจำลอง
จนจบหนึ่งรอบ โดยยังไม่ต้องต่อ Wi-Fi หรือมีฮาร์ดแวร์จริง

## ก่อนเริ่ม

- เข้าสู่ระบบและเปิดหน้าโปรเจกต์
- ตรวจว่าอยู่ในเวิร์กสเปซที่ต้องการ
- หากเคยสร้างงานไว้แล้ว ให้ใช้โปรเจกต์ทดลองแยกจากงานสำคัญ

## 1. สร้างโปรเจกต์

1. กดสร้างโปรเจกต์ใหม่ ตั้งชื่อ เช่น “ESP32 serial demo”
2. เลือก **ตั้งค่าเอง** และบอร์ด ESP32 จากรายการ
3. เลือกเฟรมเวิร์ก **PlatformIO**
4. ยังไม่ต้องเพิ่มอุปกรณ์เสริม แล้วกดสร้าง
5. เมื่อเปิด Virtual Device แล้ว ตรวจว่ามีบอร์ด จากนั้นเปิด IDE ของโปรเจกต์เดียวกัน

## 2. เปิดและแก้ไฟล์หลัก

เปิด `src/main.cpp` แล้วแทนเนื้อหาด้วยตัวอย่างนี้:

```cpp
#include <Arduino.h>

void setup() {
  Serial.begin(115200);
  Serial.println("IoT Hub ready");
}

void loop() {
  Serial.println("Hello from ESP32");
  delay(1000);
}
```

ถ้าเลือก Arduino C++ ไว้ ให้ใช้ `main.ino` และไม่ต้องใส่บรรทัด `#include <Arduino.h>`
ไม่ต้องสร้างไฟล์หลักซ้ำสองไฟล์

`setup()` ใช้เริ่มต้นหนึ่งครั้ง ส่วน `loop()` ทำงานซ้ำ ตัวอย่างนี้พิมพ์ข้อความแล้วเว้นช่วง
เพื่อให้สังเกตผลได้ง่าย ก่อนเพิ่มการอ่านเซนเซอร์ในบทถัดไป

## 3. บันทึกก่อนจำลอง

กด **Save** หรือ `Ctrl+S` แล้วรอข้อความบันทึกไปยังเวิร์กสเปซสำเร็จ
ถ้าระบบแจ้งว่าบันทึกได้เฉพาะในเบราว์เซอร์ ให้แก้การเชื่อมต่อก่อนเริ่มทดสอบ
เพราะตัวจำลองต้องอ่านโค้ดฉบับที่บันทึกแล้ว

## 4. เปิด Virtual Device และกด Start

1. เปิดหน้าจำลองของโปรเจกต์
2. กด **Start**
3. เปิด **Serial monitor** จากแถบเครื่องมือ
4. ตรวจข้อความ `Hello from ESP32` ที่ออกซ้ำประมาณหนึ่งครั้งต่อวินาที

ข้อความ `IoT Hub ready` อยู่ช่วงเริ่มต้น ส่วนข้อความที่ออกซ้ำช่วยยืนยันว่า `loop()` ยังทำงาน
หน้าจำลองนี้ไม่ต้องเลือกพอร์ต USB

## 5. ทดลองเปลี่ยนพฤติกรรม

กด **Stop** กลับ IDE เปลี่ยนข้อความเป็น `My first IoT project` บันทึก แล้วเริ่มจำลองใหม่
หากเห็นข้อความใหม่ แสดงว่าคุณทำครบวงจรแก้โค้ด → บันทึก → รัน → ตรวจผลแล้ว

## ถ้าไม่เห็นผล

| อาการ | วิธีตรวจ |
| --- | --- |
| ขึ้นข้อผิดพลาดของโค้ด | ตรวจวงเล็บ เครื่องหมายอัฒภาค และไฟล์หลัก |
| ยังเป็นข้อความเก่า | ตรวจผล Save แล้ว Stop/Start ใหม่ |
| Serial ว่าง | ตรวจว่าดู monitor ของ Virtual Device และเริ่มจำลองแล้ว |
| โหลดโปรเจกต์ไม่ได้ | ตรวจการเชื่อมต่อและบัญชี ก่อนแก้โค้ด |

## ทำอะไรต่อ

- อ่าน **ต่อวงจรใน Virtual Device** แล้วเพิ่มอุปกรณ์ครั้งละหนึ่งตัว
- อ่าน **ใช้ผู้ช่วย AI กับโปรเจกต์** เพื่อขอคำอธิบายหรือแผนเพิ่มความสามารถ
- เมื่อจะใช้บอร์ดจริง อ่าน **Compile อัปโหลด และตรวจบอร์ดจริง** เพื่อเตรียมพอร์ตและเครื่องมือ
