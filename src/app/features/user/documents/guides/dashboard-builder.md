Dashboard ใช้ออกแบบหน้าจอแสดงผลของโปรเจกต์ บทนี้พาจัดวางวิดเจ็ต ปรับการแสดงผล
และตรวจหน้าจอหลายขนาด ก่อนเริ่มให้มีโปรเจกต์แล้ว

> รุ่นปัจจุบันบันทึกเลย์เอาต์ในเบราว์เซอร์ การกด Publish ยังไม่ได้สร้างเว็บไซต์สาธารณะ
> หรือยืนยันว่ามีข้อมูลสดจากบอร์ด ควรใช้หน้านี้สำหรับออกแบบและดูตัวอย่าง

## 1. เปิดหน้าและตั้งชื่อ

เปิดมุมมอง Dashboard ของโปรเจกต์ ตรวจชื่อโปรเจกต์ที่ด้านบน แล้วตั้งชื่อแดชบอร์ด
ให้สื่อถึงงาน เช่น “Greenhouse overview”

## 2. เพิ่มวิดเจ็ต

1. เปิดแผงรายการวิดเจ็ต
2. เลือกชนิดที่สื่อข้อมูลที่ต้องการจากรายการที่มี
3. เพิ่มลงพื้นที่ทำงาน
4. เลือกวิดเจ็ตแล้วเปิด **Widget settings**
5. ตั้ง **Widget title** และข้อความประกอบให้เข้าใจได้โดยไม่ต้องเดา

เริ่มด้วยวิดเจ็ตจำนวนน้อย ตรวจการจัดวางให้เรียบร้อย แล้วค่อยเพิ่มรายละเอียด
ชื่ออย่าง “อุณหภูมิอากาศ” ชัดกว่าชื่อ “Sensor 1”

## 3. จัดตำแหน่งและขนาด

ลากวิดเจ็ตไปยังตำแหน่งที่ต้องการ หรือปรับค่าตำแหน่งใน **Grid position**
ใช้ Undo/Redo เมื่อต้องย้อนงาน และ Duplicate เมื่อต้องการสำเนาวิดเจ็ตที่ตั้งค่าไว้แล้ว

ถ้าขยับไม่ได้ ให้ตรวจว่าอยู่ในโหมดแก้ไข และไม่ได้เปิด **Lock layout**
รวมถึงตรวจสถานะล็อกของวิดเจ็ตนั้นด้วย

## 4. ปรับชื่อ รูปแบบ และการตั้งค่าข้อมูล

เลือกวิดเจ็ตทีละตัวแล้วตรวจแท็บการตั้งค่าที่มีสำหรับชนิดนั้น
ใส่หน่วยในช่องที่รองรับและใช้ชื่อให้สอดคล้องกับข้อมูล เช่น ไม่ตั้งชื่อความชื้นให้ค่าที่แทนอุณหภูมิ

ค่าที่เห็นในตัวอย่างยังไม่ใช่หลักฐานว่าได้รับข้อมูลจากอุปกรณ์
การเลือกแหล่งข้อมูลหรือพิมพ์ชื่อค่าในตัวแก้ไขเพียงอย่างเดียวไม่ยืนยันการเชื่อมต่อจริง

## 5. ตรวจหลายขนาดหน้าจอ

ใช้ตัวเลือกเลย์เอาต์ด้านบนเพื่อสลับขนาดที่หน้านี้รองรับ ตรวจแต่ละขนาดแยกกัน:

- ข้อความสำคัญถูกตัดหรือไม่
- วิดเจ็ตซ้อนทับหรือออกนอกพื้นที่หรือไม่
- ลำดับการอ่านยังเข้าใจเมื่อพื้นที่แคบลงหรือไม่
- ชื่อและหน่วยยังอยู่ใกล้ค่าที่อธิบายหรือไม่

## 6. ดูตัวอย่างและบันทึก

1. กด **Preview** เพื่อดูหน้าตาเมื่อไม่ได้แก้ไข
2. กด **Back to editor** เมื่อต้องปรับต่อ
3. กด **Save** และตรวจสถานะการบันทึก
4. เปิดหน้านี้ซ้ำในเบราว์เซอร์เดิมเพื่อตรวจเลย์เอาต์

หลีกเลี่ยงการล้างข้อมูลเว็บไซต์ถ้ายังต้องใช้เลย์เอาต์นี้ การเปิดแบบส่วนตัวหรือเปลี่ยนเบราว์เซอร์
อาจทำให้ไม่มีข้อมูลที่บันทึกไว้ในบริบทเดิม

## ปัญหาที่พบบ่อย

| อาการ | วิธีตรวจ |
| --- | --- |
| ไม่เห็นแผงวิดเจ็ต | เปิดแผงรายการและกลับเข้าโหมดแก้ไข |
| เลือกแล้วไม่เห็นการตั้งค่า | เปิด inspector และเลือกวิดเจ็ตอีกครั้ง |
| ลากไม่ได้ | ตรวจ Preview, Lock layout และการล็อกเฉพาะวิดเจ็ต |
| เปิดอีกเครื่องแล้วงานหาย | เลย์เอาต์ปัจจุบันเก็บในเบราว์เซอร์เดิม |
| Publish แล้วไม่มีลิงก์ | ยังไม่มีขั้นตอนเผยแพร่สาธารณะจริงจากปุ่มนี้ |

ขั้นตอนนี้สำเร็จเมื่อจัดหน้าจอได้ตามต้องการ ดูตัวอย่างได้ และเปิดเลย์เอาต์เดิมซ้ำในเบราว์เซอร์ได้
