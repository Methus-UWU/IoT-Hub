ชุมชนเปิดให้อ่านกระทู้ได้ก่อนเข้าสู่ระบบ ส่วนการตั้งกระทู้ ตอบ และโหวตต้องเข้าสู่ระบบ
บทนี้พาตั้งคำถามที่มีข้อมูลพอให้ผู้อื่นช่วย และติดตามคำตอบจนตรวจผลได้

## 1. ค้นหาก่อนตั้งกระทู้

เปิด **ชุมชน** แล้วค้นหาชื่อบอร์ด เซนเซอร์ หรือข้อความผิดพลาดสั้น ๆ
ใช้แท็บ **ล่าสุด**, **เคลื่อนไหว** หรือ **ยอดนิยม** และกรองด้วยหัวข้อทางด้านข้าง
ถ้าผลน้อยเกินไป ให้ล้างตัวกรองก่อนเปลี่ยนคำค้น กด **โหลดเพิ่ม** เมื่อยังมีรายการต่อ

## 2. เลือกประเภทกระทู้

กด **ตั้งกระทู้** แล้วเลือกประเภท:

| ประเภท | ใช้เมื่อ |
| --- | --- |
| คำถาม | มีปัญหาที่อยากได้วิธีแก้ |
| พูดคุย | อยากแลกเปลี่ยนแนวคิดหรือประสบการณ์ |
| อวดผลงาน | มีงานที่ทำสำเร็จและอยากแบ่งปัน |

## 3. กรอกชื่อ รายละเอียด และหัวข้อ

- ชื่อกระทู้ยาว 10–160 ตัวอักษร และควรบอกทั้งอุปกรณ์กับอาการ
- รายละเอียดมี 20–20,000 ตัวอักษร ใช้ Markdown จัดหัวข้อและบล็อกโค้ดได้
- เลือกหัวข้อที่เกี่ยวข้องอย่างน้อยหนึ่งและไม่เกินห้าหัวข้อ

ตัวอย่างชื่อ: “ESP32 จำลองแล้ว Serial ไม่แสดงข้อความหลังเพิ่มปุ่มกด”
มีประโยชน์กว่าชื่อ “ช่วยด้วยครับ” เพราะผู้อ่านรู้ขอบเขตก่อนเปิดกระทู้

## แม่แบบคำถามที่นำไปใช้ได้

```text
เป้าหมาย: ต้องการให้กดปุ่มแล้ว Serial แสดงสถานะ
บอร์ดและเฟรมเวิร์ก: ระบุรุ่นที่เลือกและเฟรมเวิร์ก
ทดสอบที่ไหน: Virtual Device หรือบอร์ดจริง
วงจร: ระบุชื่อขาต้นทางและปลายทาง
ขั้นตอนที่ทำ: บันทึกไฟล์ เปิดหน้าจำลอง กด Start แล้วกดปุ่ม
ผลที่คาด: มีข้อความเมื่อกดปุ่ม
ผลที่พบ: ระบุสิ่งที่เห็นจริงและข้อความผิดพลาด
สิ่งที่ลองแล้ว: ระบุทีละข้อพร้อมผล
```

เพิ่มโค้ดเฉพาะส่วนที่จำเป็นด้วยบล็อกโค้ด Markdown และแทนรหัสผ่านหรือคีย์จริงด้วยข้อความสมมติ
อย่าใส่ไฟล์ตั้งค่าทั้งไฟล์ถ้ามีข้อมูลบัญชีหรือข้อมูลลับปนอยู่

## 4. ดูตัวอย่างก่อนส่ง

ใช้ปุ่มดูตัวอย่างเพื่อตรวจว่าโค้ดขึ้นบรรทัดถูก หัวข้ออ่านง่าย และรายละเอียดครบ
กลับไปแก้ถ้ายังขาด แล้วจึงส่ง รอจนเปิดหน้ากระทู้และเห็นข้อความของคุณก่อนถือว่าส่งสำเร็จ

ถ้าปุ่มส่งยังใช้ไม่ได้ ให้ตรวจความยาวชื่อ เนื้อหา และการเลือกหัวข้อ
ถ้าโหลดหัวข้อไม่ได้ ให้ลองโหลดใหม่ก่อนส่ง

## 5. ตอบและสนทนาต่อ

เขียนวิธีแก้ในช่อง **คำตอบของคุณ** แล้วกด **ส่งคำตอบ**
หากเป็นการถามรายละเอียดของคำตอบหนึ่ง ใช้ตอบกลับใต้คำตอบนั้นเพื่อให้บทสนทนาอยู่ด้วยกัน
กดเครื่องหมายย่อหรือขยายเมื่อต้องการลดความยาวของหน้า

ผู้เขียนแก้ไขหรือลบคำตอบและข้อความตอบกลับของตัวเองได้จากเมนูใต้ข้อความ
การลบมีขั้นยืนยัน อ่านข้อความก่อนยืนยันทุกครั้ง

## 6. โหวตและยอมรับคำตอบ

ใช้โหวตเพื่อบอกว่าคำตอบมีประโยชน์ หลังทดลองแล้วผู้ตั้งกระทู้สามารถทำเครื่องหมาย
ว่าคำตอบใดแก้ปัญหาได้ และยกเลิกการยอมรับได้ถ้าตรวจพบว่าไม่ตรง

คะแนนโหวตและเครื่องหมายยอมรับมีหน้าที่ต่างกัน: คะแนนเป็นความเห็นของผู้โหวต
ส่วนการยอมรับเป็นผลที่ผู้ตั้งกระทู้เลือกให้กับปัญหาของตน

## 7. เมื่อต้องลบหรือรายงานปัญหา

ผู้ตั้งกระทู้ใช้ **ลบกระทู้** และยืนยันลบได้ การลบเป็นการลบถาวร
คัดลอกเนื้อหาที่ต้องการเก็บก่อน หากส่งข้อความไม่สำเร็จให้สำรองข้อความก่อนรีโหลดหน้า

เมื่อกลับมาอ่านลิงก์แล้วไม่พบกระทู้ ให้ตรวจ URL และค้นหาจากหน้าชุมชนอีกครั้ง
กระทู้อาจถูกลบแล้ว จึงไม่ควรส่งคำตอบซ้ำจากแท็บเก่า
