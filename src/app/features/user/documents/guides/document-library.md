หน้าเอกสารรวมคู่มือการใช้งานกับข้อมูลอุปกรณ์ที่มีใน Virtual Device
เปิดอ่านได้จากหน้า **เอกสาร** ก่อนเข้าสู่ระบบ หรือจากเมนูเอกสารในพื้นที่ผู้ใช้

## 1. เลือกแท็บให้ตรงสิ่งที่หา

| แท็บ | เหมาะกับคำถาม |
| --- | --- |
| คู่มือ | เริ่มโปรเจกต์อย่างไร บันทึกโค้ดตรงไหน ใช้ AI อย่างไร |
| ข้อมูลอุปกรณ์ | อุปกรณ์นี้ทำอะไร ขาไหนใช้ต่อสาย มีข้อจำกัดอะไร |

เมื่อสลับแท็บ คำค้นจะถูกล้าง ให้พิมพ์คำค้นใหม่สำหรับรายการที่ต้องการ

## 2. ค้นหาคู่มือ

1. เลือกแท็บ **คู่มือ**
2. เลือกหมวดที่ตรงกับงาน หรือ **คู่มือทั้งหมด**
3. พิมพ์ชื่อเรื่องหรือคำสั้น ๆ เช่น `IDE`, `AI`, `Serial` หรือ `ชุมชน`
4. อ่านคำอธิบายบนการ์ดแล้วเปิดบทที่ต้องการ

การค้นหาคู่มือจับจากชื่อและคำอธิบาย ยังไม่ได้ค้นทั้งเนื้อหาบท
ถ้าค้นประโยคยาวแล้วไม่พบ ลองคำสั้นลงและล้างตัวกรองหมวด

## 3. อ่านข้อมูลอุปกรณ์

1. เลือกแท็บ **ข้อมูลอุปกรณ์**
2. เลือกหมวดอุปกรณ์หรือค้นหาชื่อไทย ชื่ออังกฤษ หรือรุ่น
3. เปิดการ์ดแล้วตรวจรูป ชื่อรุ่น และคำอธิบาย
4. อ่านหน้าที่ ข้อควรระวัง และตารางขา
5. อ่านรายละเอียดการต่อและตัวอย่างโค้ดในส่วนเอกสารของอุปกรณ์

รูปช่วยระบุอุปกรณ์ ส่วนตารางขาใช้ตรวจชื่อและหน้าที่ของจุดต่อ
ก่อนประกอบฮาร์ดแวร์จริงให้เทียบรุ่นและข้อมูลของผู้ผลิตด้วย เพราะเอกสารหน้านี้เป็นคู่มือที่เรียบเรียงไว้

## 4. เปรียบเทียบอุปกรณ์ 2–4 ชิ้น

1. เลือกเพิ่มอุปกรณ์เข้าสู่รายการเปรียบเทียบจากการ์ด
2. เลือกอย่างน้อยสองชิ้น และได้สูงสุดสี่ชิ้น
3. เปลี่ยนคำค้นหรือหมวดเพื่อเลือกข้ามหมวดได้
4. กด **เปรียบเทียบ** จากแถบรายการที่เลือก
5. เทียบความสามารถ งานที่เหมาะ ข้อจำกัด แรงดัน อินเทอร์เฟซ และจำนวนขา

บนหน้าจอเล็ก เลื่อนตารางในแนวนอนเพื่ออ่านทุกคอลัมน์
นำบางชิ้นออกหรือใช้คำสั่งล้างรายการเมื่อจะเริ่มเทียบชุดใหม่

อุปกรณ์ต่างหมวดอาจทำหน้าที่ต่างกัน การอยู่ในตารางเดียวกันไม่ได้แปลว่าใช้แทนกันได้
ถ้าระบุว่ายังไม่มีข้อมูลข้อจำกัด ไม่ได้แปลว่าอุปกรณ์ไม่มีข้อจำกัด

## 5. ปิดแผงอ่านและกลับรายการ

ใช้ปุ่มปิด กด `Escape` หรือคลิกพื้นที่ด้านนอกแผงอ่าน
เมื่อปิด ระบบจะพยายามคืนโฟกัสให้การ์ดที่เปิด เพื่อให้ใช้คีย์บอร์ดอ่านบทถัดไปได้ต่อเนื่อง

รายการเปรียบเทียบคงอยู่ระหว่างเปลี่ยนตัวกรองและสลับแท็บภายในหน้า
แต่ไม่ควรคาดว่าจะถูกเก็บเป็นรายการส่วนตัวถาวรหลังโหลดหน้าใหม่

## ถ้ายังไม่พบคำตอบ

จดชื่ออุปกรณ์ งานที่ต้องการทำ และจุดที่สงสัย แล้วค้นหาในชุมชน
ถ้าต้องตั้งกระทู้ใหม่ ให้แนบตัวอย่างโค้ดที่ตัดข้อมูลลับออกแล้ว
อ่านบท **ใช้งานชุมชน ถาม ตอบ และโหวต** เพื่อเตรียมคำถามให้ผู้อื่นทดลองตามได้
