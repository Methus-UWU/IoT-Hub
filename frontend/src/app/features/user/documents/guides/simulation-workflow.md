การจำลองใช้โค้ดจากโปรเจกต์ร่วมกับวงจรใน Virtual Device โดยไม่ต้องเสียบบอร์ดจริง
เป้าหมายคือเห็นว่าการเปลี่ยนอินพุตส่งผลต่อโค้ดและอุปกรณ์อย่างไร

## 1. เตรียมรอบทดสอบ

1. เปิด IDE และตรวจไฟล์หลักของโปรเจกต์
2. บันทึกโค้ดให้สำเร็จก่อนออกจาก IDE
3. เปิด Virtual Device และตรวจสายตามบทต่อวงจร
4. ตั้งเป้าหมายที่สังเกตได้ เช่น “Serial พิมพ์ข้อความทุกวินาที”

ถ้าเพิ่งเริ่ม ให้ใช้ตัวอย่างในบท **สร้างโปรเจกต์ ESP32 ตัวแรก** ก่อนเพิ่มไลบรารีหรือเซนเซอร์

## 2. เริ่มและหยุด

กด **Start** เพื่อเริ่มจำลอง ปุ่มจะเปลี่ยนเป็น **Stop** และหน้าจอแสดงสถานะการทำงาน
ระหว่างรัน การแก้โครงสร้างวงจรบางอย่าง เช่น เพิ่มหรือลบอุปกรณ์ จะถูกปิดไว้

เมื่ออยากเปลี่ยนโค้ด ให้หยุดก่อน กลับ IDE บันทึกไฟล์ แล้วเริ่มจำลองรอบใหม่
อย่าคาดว่าการพิมพ์โค้ดในอีกแท็บจะเปลี่ยนโปรแกรมที่กำลังรันอยู่ทันที

## 3. อ่าน Serial monitor

เปิด **Serial monitor** จากแถบเครื่องมือของ Virtual Device แล้วสังเกตข้อความที่โค้ดส่งออกมา
ใช้ข้อความสั้นที่บอกขั้นตอน เช่น `ready`, `input changed` หรือค่าที่กำลังอ่าน

ถ้าข้อความไม่มา ให้ตรวจตามลำดับ:

1. กด Start แล้วหรือยัง
2. มีข้อความว่าโค้ดผิดพลาดหรือหยุดทำงานหรือไม่
3. ไฟล์หลักที่บันทึกมี `Serial.begin(...)` และ `Serial.println(...)` หรือไม่
4. กำลังเปิด Serial monitor ของหน้าจำลอง ไม่ใช่หน้าของอุปกรณ์จริงใช่หรือไม่

## 4. ทดลองอินพุตทีละอย่าง

อุปกรณ์บางชนิดมีส่วนโต้ตอบระหว่างจำลอง เช่น ปุ่ม สวิตช์ หรือค่าจำลองของเซนเซอร์
ใช้ส่วนควบคุมที่อุปกรณ์นั้นแสดง แล้วตรวจผลทั้งที่อุปกรณ์ปลายทางและข้อความ Serial

จดผลการทดลองแบบง่าย:

| รอบ | สิ่งที่เปลี่ยน | สิ่งที่คาด | สิ่งที่เห็น |
| --- | --- | --- | --- |
| 1 | ยังไม่กดปุ่ม | สถานะเริ่มต้น | บันทึกผลจริง |
| 2 | กดปุ่ม | โค้ดตอบสนองหนึ่งครั้งหรือระหว่างกดตามที่เขียน | บันทึกผลจริง |
| 3 | ปล่อยปุ่ม | กลับสู่สถานะที่กำหนด | บันทึกผลจริง |

การเปลี่ยนหลายค่าพร้อมกันทำให้แยกยากว่าจุดใดเป็นสาเหตุ

## 5. แยกประเภทข้อผิดพลาด

| อาการ | เริ่มตรวจที่ไหน |
| --- | --- |
| โค้ดผิดพลาดตอนเริ่ม | รูปแบบโค้ด ไฟล์หลัก และคำสั่งที่จำลองรองรับ |
| โค้ดหยุดระหว่างรัน | ข้อความผิดพลาดล่าสุดและการเปลี่ยนอินพุตก่อนหน้า |
| โค้ดรันแต่ไม่มีผล | ไฟเลี้ยง กราวด์ สายสัญญาณ และหมายเลขขา |
| ค่าต่างจากที่คาด | คุณสมบัติของอุปกรณ์และค่าจำลองที่ตั้งไว้ |

## เข้าใจขอบเขตของผลทดสอบ

ตัวจำลองรองรับ Arduino เพียงบางส่วน ไลบรารีหรือความสามารถที่ทำงานบนบอร์ดจริง
อาจยังไม่รองรับในหน้านี้ โดยเฉพาะอย่าสรุปว่า Wi-Fi หรือบริการเครือข่ายจริงทำงานแล้ว
จากการเห็นอุปกรณ์จำลองมีสถานะออนไลน์

วงจรและไฟล์เป็นข้อมูลโปรเจกต์ ส่วนค่าขณะจำลอง เช่น สถานะปุ่มหรือค่าชั่วคราว
ไม่ควรถูกใช้เป็นหลักฐานว่าจะคงเดิมหลังโหลดหน้าใหม่

เมื่อทดลองผ่าน ให้บันทึกโค้ดและจดขั้นตอนที่ทำซ้ำได้ แล้วจึงทดสอบบนบอร์ดจริงตามความจำเป็น
