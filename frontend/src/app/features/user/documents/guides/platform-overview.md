คู่มือนี้เป็นจุดเริ่มต้นสำหรับคนที่เพิ่งเปิด IoT Hub เป้าหมายคือรู้ว่าควรเข้าหน้าไหน
ทำอะไรก่อน และตรวจอย่างไรว่างานถูกบันทึกแล้ว โดยยังไม่ต้องมีบอร์ดจริง

## เตรียมก่อนเริ่ม

- อ่านคู่มือและชุมชนได้จากหน้าเว็บสาธารณะ
- เข้าสู่ระบบก่อนสร้างหรือเปิดโปรเจกต์ของคุณ
- เตรียมชื่อโปรเจกต์และเป้าหมายสั้น ๆ เช่น “ทดลองพิมพ์ข้อความจาก ESP32”
- ถ้ามีหลายเวิร์กสเปซ ให้ตรวจชื่อเวิร์กสเปซก่อนสร้างงาน

## หน้าที่ของแต่ละหน้า

| หน้า | ใช้ทำอะไร | สิ่งที่ควรตรวจเมื่อทำเสร็จ |
| --- | --- | --- |
| โปรเจกต์ | สร้าง ค้นหา และเปิดงาน | มีการ์ดชื่อโปรเจกต์ที่สร้าง |
| IDE | แก้ไฟล์ บันทึกโค้ด และคุยกับ AI | มีข้อความบันทึกไปยังเวิร์กสเปซสำเร็จ |
| Virtual Device | วางอุปกรณ์ ต่อสาย และจำลอง | วงจรถูกต้องและไม่มีข้อผิดพลาดของโค้ด |
| Dashboard | จัดวางหน้าจอแสดงผล | ดูตัวอย่างและบันทึกเลย์เอาต์แล้ว |
| เอกสาร | อ่านคู่มือและข้อมูลอุปกรณ์ | เลือกรุ่นและอ่านตารางขาตรงกับอุปกรณ์ |
| ชุมชน | ถามปัญหา ตอบ และแบ่งปันผลงาน | กระทู้หรือคำตอบปรากฏหลังส่ง |

## เส้นทางสำหรับการทดลองครั้งแรก

1. เปิด **โปรเจกต์** แล้วเริ่มสร้างโปรเจกต์ใหม่
2. เลือก **ตั้งค่าเอง** และเลือกบอร์ด ESP32 ที่มีในรายการ
3. ยังไม่ต้องเพิ่มเซนเซอร์ สร้างโปรเจกต์ที่มีเพียงบอร์ดก่อน
4. เปิด IDE แล้วทำตามบท **สร้างโปรเจกต์ ESP32 ตัวแรก**
5. บันทึกไฟล์ จากนั้นเปิด Virtual Device และกด **Start**
6. เปิด Serial monitor ของหน้าจำลองเพื่อตรวจข้อความจากโค้ด
7. กด **Stop** ก่อนเปลี่ยนวงจร แล้วค่อยเพิ่มอุปกรณ์ตามบท **ต่อวงจรใน Virtual Device**

เมื่อทำครบ คุณควรมีโปรเจกต์ที่เปิดซ้ำได้ มีไฟล์โค้ดที่บันทึกไว้ และเห็นผลจากการจำลอง
การผ่านขั้นนี้ยังไม่ใช่การทดสอบบนฮาร์ดแวร์จริง

## เลือกวิธีเริ่มให้เหมาะกับงาน

- **ตั้งค่าเอง:** เหมาะเมื่ออยากเรียนรู้ทีละขั้นและตรวจทุกสายด้วยตัวเอง
- **เริ่มต้นกับ AI:** เหมาะเมื่ออธิบายผลที่ต้องการได้แล้ว อ่านแผนที่ AI เสนอและยอมรับก่อนนำไปใช้
- **มีบอร์ดจริง:** เริ่มจากงานเล็กที่จำลองได้ แล้วอ่านบท Compile และ Upload ก่อนเชื่อมต่อพอร์ต

## ข้อมูลใดเปิดข้ามเครื่องได้

ไฟล์โปรเจกต์และวงจรมีการบันทึกผ่านระบบ แต่ต้องตรวจว่าคำขอบันทึกสำเร็จจริง
ถ้าหน้า IDE แจ้งว่าเก็บได้เฉพาะในเบราว์เซอร์ ให้สำรองโค้ดก่อนออก

เลย์เอาต์ Dashboard ในรุ่นปัจจุบันเก็บในเบราว์เซอร์ที่ใช้งาน การเปิดจากอีกเครื่อง
หรือการล้างข้อมูลเว็บไซต์จึงไม่รับประกันว่าจะเห็นเลย์เอาต์เดิม

## อ่านต่ออย่างไร

กลับหน้ารายการคู่มือแล้วค้นหาชื่อบทที่ต้องการ:

1. **สร้างและจัดการโปรเจกต์** สำหรับการเลือกบอร์ดและรูปแบบเริ่มต้น
2. **ใช้ IDE และจัดการไฟล์โค้ด** สำหรับการเขียนและบันทึกงาน
3. **ใช้ผู้ช่วย AI กับโปรเจกต์** สำหรับการตรวจและนำข้อเสนอไปใช้
4. **แก้ปัญหาการใช้งานทีละขั้น** เมื่อผลไม่เป็นไปตามที่คาด
