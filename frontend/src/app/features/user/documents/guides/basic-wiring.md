ตัวอย่างนี้ใช้ **ESP32 DevKit รุ่น 38 ขาที่ใช้โมดูล ESP32-WROOM-32** ภาพแรกเป็นวงจรรวมที่ต่อ LED ปุ่มกด และเซนเซอร์เสียงเข้ากับบอร์ดเดียวกัน ปุ่มด้านบนภาพเปิดตัวอย่างอีก 10 วงจร ได้แก่ LED ปุ่มกด โพเทนชิโอมิเตอร์ โมดูล LDR เซนเซอร์ IR, PIR HC-SR501, DHT22, เซอร์โว SG90 รีเลย์ และจอ OLED I2C แต่ละภาพมีรายการสาย อุปกรณ์ที่ต้องใช้ และคำแนะนำการเขียนโค้ด เลือกหมายเลขสายใต้ภาพเพื่อเน้นสายที่ต้องการ หรือกด **ขยายภาพ** แล้วเลื่อนดูชื่อขา ภาพแสดงการเชื่อมต่อ ไม่ใช่การจำลองการทำงาน

เริ่มจากวงจร LED แล้วเพิ่มปุ่มกดและเซนเซอร์เสียงตามตารางด้านล่าง แต่ละอุปกรณ์ใช้ GPIO คนละขาจึงต่อร่วมกันได้ โดยใช้ LED และตัวต้านทานชุดเดิมในทุกขั้น ไม่ต้องเพิ่ม LED อีกดวง กราวด์ทุกจุดของบอร์ดเชื่อมถึงกัน หากใช้เบรดบอร์ดกระจายกราวด์ ให้ตรวจว่ารางที่เลือกเชื่อมต่อถึงกัน

ภาพ **แผนผังแยกแต่ละวงจร** เปิดดูขนาดเต็มได้จากหัวข้อที่พับไว้ด้านบน ใช้ประกอบคำอธิบายทีละขั้น

## เตรียมก่อนต่อวงจร

- เตรียมบอร์ด ESP32, สาย USB, เบรดบอร์ด, สายจัมเปอร์ และอุปกรณ์ของตัวอย่างที่ต้องการ
- ถอดสาย USB และแหล่งจ่ายไฟก่อนเปลี่ยนสายทุกครั้ง จ่ายไฟให้บอร์ดผ่าน USB เมื่อเช็กวงจรเสร็จแล้ว
- ชื่อ GPIO ในภาพคือหมายเลขที่ใช้ในโค้ด ไม่ใช่ลำดับตำแหน่งขา ภาพย่อแสดงเฉพาะขาที่ใช้งาน
- สายสีแดงคือไฟเลี้ยง 3.3V สายสีดำคือ GND สายสีน้ำเงินและสีส้มคือสัญญาณ ให้ยึดชื่อขาและตารางประกอบ ไม่ใช้สีสายเพียงอย่างเดียว
- ตัวอย่างนี้ใช้สัญญาณระดับ 3.3V ห้ามนำเอาต์พุต 5V ต่อเข้า GPIO ของ ESP32 โดยตรง และต้องต่อ GND ร่วมกัน

## 1. ต่อ LED ผ่านตัวต้านทาน

**อุปกรณ์:** LED สีแดง 1 ดวง และตัวต้านทาน 220 Ω 1 ตัว

| จาก                             | ต่อไปที่                         |
| ------------------------------- | -------------------------------- |
| ESP32 GPIO 23                   | ปลายด้านหนึ่งของตัวต้านทาน 220 Ω |
| ปลายอีกด้านของตัวต้านทาน        | ขา A (Anode / ขั้วบวก) ของ LED   |
| ขา K (Cathode / ขั้วลบ) ของ LED | ESP32 GND                        |

ตั้ง `pinMode(23, OUTPUT)` จากนั้น `digitalWrite(23, HIGH)` เพื่อเปิด LED และ `digitalWrite(23, LOW)` เพื่อปิด

LED ใหม่โดยทั่วไปมีขายาวเป็น A และขาสั้นหรือด้านแบนของตัวถังเป็น K ตรวจขั้วก่อนใช้งาน และต้องมีตัวต้านทานอนุกรมเสมอ หากไม่ติด ให้ตรวจขั้ว LED และหมายเลข GPIO

## 2. ต่อปุ่มกดแบบใช้ตัวต้านทานพูลอัปภายใน

**อุปกรณ์:** ปุ่มกดแบบชั่วขณะ 1 ตัว

| จาก                      | ต่อไปที่                   |
| ------------------------ | -------------------------- |
| ESP32 GPIO 18            | หน้าสัมผัสด้านหนึ่งของปุ่ม |
| หน้าสัมผัสอีกด้านของปุ่ม | ESP32 GND                  |

ตั้ง `pinMode(18, INPUT_PULLUP)` แล้วอ่านด้วย `digitalRead(18)` เมื่อปล่อยปุ่มจะได้ `HIGH` และเมื่อกดจะได้ `LOW` ไม่ต้องต่อไฟ 3.3V เข้าปุ่มในวงจรนี้

ปุ่มกด 4 ขามีขาบางคู่เชื่อมกันอยู่แล้ว ให้ใช้หน้าสัมผัสคนละชุดที่เชื่อมถึงกันเฉพาะตอนกด ตรวจด้วยมัลติมิเตอร์หรือเอกสารของปุ่ม หากอ่านได้ `LOW` ตลอด อาจเลือกขาคู่ที่เชื่อมกันถาวร ในงานนับจำนวนครั้งที่กดควรกรองการเด้งของหน้าสัมผัส (debounce) เพิ่มในโค้ด

## 3. ต่อเซนเซอร์เสียงเพื่อควบคุม LED

**อุปกรณ์:** โมดูลไมโครโฟน KY-038 ที่รองรับไฟเลี้ยง 3.3V, LED สีแดง และตัวต้านทาน 220 Ω

| จาก                            | ต่อไปที่                        |
| ------------------------------ | ------------------------------- |
| ESP32 3V3                      | ขา + / VCC ของ KY-038           |
| ESP32 GND                      | ขา G / GND ของ KY-038           |
| ขา DO (Digital Out) ของ KY-038 | ESP32 GPIO 19                   |
| ESP32 GPIO 23                  | ตัวต้านทาน 220 Ω → ขา A ของ LED |
| ขา K ของ LED                   | ESP32 GND                       |
| ขา AO (Analog Out) ของ KY-038  | ไม่ต่อในตัวอย่างนี้             |

ตั้ง GPIO 19 เป็น `INPUT` และ GPIO 23 เป็น `OUTPUT` ใช้ค่าจาก `digitalRead(19)` ตรวจการข้ามระดับเสียงที่ตั้งไว้ แล้วสั่งเปิดหรือปิด LED หมุนตัวปรับบนโมดูลและดูค่าผ่าน Serial ขณะเงียบและขณะมีเสียงก่อนกำหนดเงื่อนไข เพราะระดับ `HIGH` / `LOW` ที่หมายถึงตรวจพบเสียงอาจต่างกันตามโมดูล

ขา DO ใช้ตรวจการข้ามเกณฑ์ ไม่ใช่ค่าความดังเป็นเดซิเบล และวงจรอย่างเดียวไม่ทำให้ LED ตอบสนองต่อเสียง ต้องมีโค้ดอ่านเซนเซอร์และสั่ง LED ด้วย หากต้องการให้เสียงสั้น ๆ มองเห็นชัด ให้โค้ดค้างไฟ LED ไว้ช่วงสั้นก่อนปิด

**ตรวจรุ่นจริงก่อนต่อ:** โมดูลเสียงแบบ 3 ขาอาจเขียน `OUT` ส่วนแบบ 4 ขามักมีทั้ง `AO` และ `DO` ตำแหน่งขาไม่เหมือนกันทุกรุ่น ตัวอย่างนี้ใช้เอาต์พุตดิจิทัลของ KY-038 ที่เลี้ยงด้วย 3.3V อย่าต่อ VCC เข้าขา VIN/5V ตามภาพของบอร์ดหรือโมดูลคนละรุ่นโดยไม่ตรวจแรงดันสัญญาณก่อน

## ใช้ภาพร่วมกับคู่มืออื่น

เปิดหมวด **อุปกรณ์และบอร์ด → ต่อวงจรใน Virtual Device** เพื่อฝึกวางอุปกรณ์และลากสาย หรือเปิดแท็บ **ข้อมูลอุปกรณ์** เพื่อตรวจขาของรุ่นที่เลือก ภาพนี้เป็นตัวอย่างการต่อวงจร ไม่ได้เริ่มการจำลองหรือเพิ่มอุปกรณ์เข้าโปรเจกต์ให้อัตโนมัติ
