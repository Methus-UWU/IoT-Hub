เมื่อใช้งานไม่สำเร็จ ให้เริ่มจากแยกว่าปัญหาเกิดระหว่างโหลดข้อมูล บันทึก จำลอง หรือทำงานกับบอร์ดจริง
การรู้ขั้นตอนที่ล้มเหลวช่วยลดการแก้โค้ดที่ไม่เกี่ยวข้อง

## ก่อนรีโหลดหน้า

1. คัดลอกโค้ดหรือข้อความที่ยังไม่บันทึกไปเก็บไว้
2. จดชื่อโปรเจกต์ หน้า และการกระทำล่าสุด
3. เก็บข้อความผิดพลาดแรกพร้อมเวลาโดยประมาณ
4. ตรวจว่าปัญหาเกิดในทุกโปรเจกต์หรือเฉพาะงานนี้

อย่าล้างข้อมูลเว็บไซต์เป็นขั้นแรก เพราะอาจลบเลย์เอาต์ Dashboard และสำเนาไฟล์ในเบราว์เซอร์

## ตารางเริ่มตรวจ

| อาการ | ตรวจและทำต่อ |
| --- | --- |
| หน้าโปรเจกต์โหลดไม่ได้ | ตรวจการเชื่อมต่อ บัญชี และเวิร์กสเปซ แล้วลองใหม่ |
| สร้างโปรเจกต์ไม่ได้ | อ่านข้อผิดพลาดของช่องกรอก บอร์ด โควตา และสิทธิ์ |
| ไฟล์กลับเป็นฉบับเก่า | ตรวจว่าบันทึกถึงเวิร์กสเปซสำเร็จหรือเก็บเฉพาะในเบราว์เซอร์ |
| บันทึกชนกับอีกแท็บ | สำรองฉบับที่แก้ โหลดข้อมูลล่าสุด และรวมการเปลี่ยนแปลง |
| เพิ่มอุปกรณ์ไม่ได้ | หยุดการจำลองและตรวจข้อจำกัดจำนวนอุปกรณ์ |
| คลิกสายไม่ได้ | เปิดโหมดแก้ไขสาย |
| Start แล้วโค้ดผิดพลาด | ตรวจไฟล์หลักและคำสั่งที่ตัวจำลองรองรับ |
| Serial ว่าง | ตรวจเป้าหมายจำลอง/จริงและคำสั่งพิมพ์ข้อความในโค้ด |
| AI ไม่ตอบ | อ่านข้อผิดพลาด ตรวจการเชื่อมต่อ แล้วแบ่งคำขอให้เล็กลง |
| ยอมรับแผน AI ไม่ได้ | โปรเจกต์อาจเปลี่ยนแล้ว ให้ขอแผนจากข้อมูลล่าสุด |
| ไม่พบพอร์ต USB | ใช้ Chrome/Edge บนคอมพิวเตอร์ กด "เพิ่มอุปกรณ์…" ตรวจสายรับส่งข้อมูลและไดรเวอร์ CP210x/CH340 |
| Dashboard หายเมื่อเปลี่ยนเครื่อง | เปิดจากเบราว์เซอร์เดิมที่บันทึกไว้ |
| ค้นคู่มือไม่เจอ | ล้างหมวดและค้นคำจากชื่อหรือคำอธิบาย |
| ส่งกระทู้ไม่ได้ | ตรวจความยาวข้อความ หัวข้อที่เลือก และการเข้าสู่ระบบ |

## แยก Compile, Upload และ Simulation

**Compile ล้มเหลว:** อ่าน Compile output เริ่มจากข้อผิดพลาดแรกที่ระบุไฟล์และบรรทัด
ถ้าระบบแจ้งว่างานยังไม่เริ่มเพราะบันทึกไม่ได้ ให้แก้การเชื่อมต่อก่อน

**Upload ล้มเหลว:** ตรวจว่าเลือกอุปกรณ์จริงและพอร์ตถูกต้อง ปิดโปรแกรมอื่นที่อาจใช้พอร์ต
ถ้าเชื่อมต่อ bootloader ไม่ได้ ให้กดปุ่ม BOOT ค้างไว้ (ESP32) แล้ว Upload อีกครั้ง

**Simulation ล้มเหลว:** ตรวจข้อผิดพลาดบน Virtual Device และลดโค้ดเหลือส่วนเล็กที่ทำซ้ำได้
การที่ไลบรารีทำงานบนบอร์ดจริงไม่ได้รับประกันว่าตัวจำลองจะรองรับ

## วิธีลดปัญหาให้เหลือจุดเดียว

1. เก็บสำเนางานปัจจุบันก่อนทดลอง
2. เริ่มจากโค้ดพิมพ์ข้อความโดยยังไม่เพิ่มความสามารถอื่น
3. เพิ่มการอ่านอินพุตหรือสั่งเอาต์พุตทีละอย่าง
4. ทดสอบหลังเปลี่ยนแต่ละจุดและจดผล
5. เมื่อพบจุดที่ทำให้เสีย ให้เก็บตัวอย่างนั้นไว้เพื่อถามต่อ

## ข้อมูลที่ควรส่งเมื่อขอความช่วยเหลือ

- หน้าและงานที่กำลังทำ เช่น IDE → Save หรือ Virtual Device → Start
- รุ่นบอร์ด เฟรมเวิร์ก และชื่ออุปกรณ์ที่เกี่ยวข้อง
- ใช้บอร์ดจริงหรือจำลอง และพอร์ตอยู่บนเครื่องใดถ้าเกี่ยวข้อง
- ขั้นตอนที่ทำซ้ำได้ ผลที่คาด และผลที่เห็น
- ข้อความผิดพลาดแรกและโค้ดส่วนที่เกี่ยวข้อง

ตัดรหัสผ่าน คีย์ และข้อมูลบัญชีออกก่อนโพสต์ชุมชน
เมื่อแก้สำเร็จแล้วให้ทำขั้นตอนเดิมซ้ำอีกครั้ง เพื่อยืนยันว่าปัญหาหายจากสาเหตุที่แก้จริง
