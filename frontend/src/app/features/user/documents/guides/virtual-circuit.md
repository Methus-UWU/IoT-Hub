Virtual Device ใช้จัดวางบอร์ด อุปกรณ์ และสายของโปรเจกต์ บทนี้เน้นสร้างวงจรและตรวจการต่อ
ส่วนการรันโค้ดอ่านต่อในบท **จำลองโค้ดและอ่าน Serial monitor**

## ก่อนต่อสาย

1. เปิด Virtual Device ของโปรเจกต์ที่ต้องการ
2. รอให้อุปกรณ์และวงจรเดิมโหลดเสร็จ
3. ถ้ากำลังจำลองอยู่ ให้กด **Stop** ก่อน
4. อ่านข้อมูลของอุปกรณ์ในหน้าเอกสาร โดยเฉพาะชื่อขา แรงดัน และหน้าที่

อย่าใช้ตำแหน่งรูปวาดแทนชื่อขา อุปกรณ์หน้าตาคล้ายกันอาจมีการเรียงขาต่างกัน

## 1. เพิ่มอุปกรณ์

กด **Add device** หรือ `A` เพื่อเปิดรายการ ค้นหารุ่นที่ต้องการแล้วเพิ่มลงพื้นที่วงจร
เริ่มทีละชิ้น เช่น บอร์ดกับอุปกรณ์หนึ่งตัว เพื่อให้ตรวจปัญหาได้ง่าย

หากเพิ่มไม่ได้ ให้ตรวจว่ากำลังรันการจำลองหรือมีข้อความจำกัดจำนวนอุปกรณ์อยู่หรือไม่
การกดเพิ่มซ้ำขณะคำขอยังไม่เสร็จอาจทำให้สับสนว่าต้องการกี่ชิ้น

## 2. จัดวางให้ตามสายได้ง่าย

- เลือกอุปกรณ์แล้วลากไปตำแหน่งที่ต้องการ
- ใช้ **Rotate** หรือ `R` เพื่อหมุนชิ้นที่เลือก
- เปิด **Grid and snap** หรือ `G` เมื่อต้องการวางตามกริด
- ใช้ **Fit diagram** หรือ `F` เพื่อแสดงวงจรทั้งหมด
- ใช้ปุ่มซูมเข้าหรือออกเมื่อขามีขนาดเล็ก
- ใช้ปุ่มจัดวางอัตโนมัติเมื่ออุปกรณ์เริ่มซ้อนกัน แล้วตรวจผลอีกครั้ง

## 3. ต่อสายโดยระบุปลายทั้งสอง

1. เลือกขาต้นทางของอุปกรณ์
2. เลือกขาปลายทางที่ต้องการเชื่อม
3. ตรวจชื่อขาทั้งสองด้านและอ่านข้อความเตือนที่เกิดขึ้น
4. ต่อไฟเลี้ยง กราวด์ และสัญญาณให้ครบตามคู่มือของรุ่นนั้น
5. เทียบหมายเลขขาสัญญาณกับโค้ด เช่น สายอยู่ GPIO 4 โค้ดต้องอ้างขาที่ตรงกัน

สีสายช่วยจัดระเบียบภาพ แต่สีเพียงอย่างเดียวไม่ได้กำหนดหน้าที่ทางไฟฟ้า
ให้ยึดปลายสายและชื่อขาเป็นหลัก

## 4. แก้สายหรืออุปกรณ์

หากคลิกเส้นแล้วเลือกไม่ได้ ให้เปิดโหมดแก้ไขสายก่อน เพราะค่าเริ่มต้นให้คลิกผ่านสายไปยังอุปกรณ์ได้
จากนั้นเลือกสายที่ต้องการแล้วใช้ Delete การลบอุปกรณ์ให้เลือกตัวอุปกรณ์ก่อน

ใช้ **Undo** (`Ctrl+Z`) และ **Redo** (`Ctrl+Shift+Z`) เมื่อต้องย้อนการแก้ไขที่หน้านี้รองรับ
หลังย้อน ให้ตรวจวงจรที่เห็นและข้อความบันทึกทุกครั้ง

## เช็กลิสต์ก่อนกด Start

| ตรวจ | เหตุผล |
| --- | --- |
| รุ่นอุปกรณ์ตรงกับคู่มือ | ชื่อขาและแรงดันอาจต่างกัน |
| ต่อไฟและกราวด์ครบ | สายสัญญาณอย่างเดียวไม่ทำให้อุปกรณ์ทำงาน |
| ขาในโค้ดตรงกับสาย | ลดปัญหาอ่านผิดขาหรือสั่งงานผิดจุด |
| ไม่มีคำเตือนที่ยังไม่เข้าใจ | วงจรอาจต่อได้แต่ทำงานผิด |
| บันทึกการเปลี่ยนแปลงสำเร็จ | เปิดหน้าซ้ำแล้วไม่กลับไปฉบับเดิม |

## ตรวจว่างานยังอยู่

เมื่อคำขอบันทึกเสร็จแล้ว ลองออกจากหน้าและกลับเข้ามา ตรวจจำนวนอุปกรณ์ ตำแหน่ง และสาย
ถ้ามีข้อความโหลดหรือบันทึกล้มเหลว ให้แก้ปัญหาการเชื่อมต่อก่อนเปลี่ยนวงจรเพิ่มเติม

การจำลองช่วยตรวจตรรกะและการต่อภายในขอบเขตที่รองรับ
ก่อนประกอบจริงยังต้องตรวจข้อมูลของบอร์ดและอุปกรณ์รุ่นที่ถืออยู่
