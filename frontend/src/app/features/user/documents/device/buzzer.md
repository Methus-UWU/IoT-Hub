## ภาพรวม

บัซเซอร์มีสองแบบที่ดูเหมือนกันจากภายนอกแต่ใช้ต่างกันสิ้นเชิง เลือกผิดแบบแล้วจะไม่มีเสียงหรือ
เสียงเปลี่ยนไม่ได้

| หัวข้อ | แบบมีวงจรกำเนิดเสียง | แบบไม่มีวงจรกำเนิดเสียง |
| --- | --- | --- |
| จ่ายไฟตรงแล้ว | ดังทันที | เงียบ หรือมีเสียงคลิกเดียว |
| ความถี่ | คงที่ ราว 2 kHz เปลี่ยนไม่ได้ | เปลี่ยนได้ตามสัญญาณที่ป้อน |
| ต้องใช้ | `digitalWrite` | `tone()` หรือ PWM |
| ความสูงตัวถัง | สูงกว่า | เตี้ยกว่า |
| ด้านใต้ | ปิดทึบ | เห็นแผ่นวงจรสีเขียว |

วิธีแยกที่แน่ที่สุด: ต่อกับถ่าน 3 V ถ้าดังทันทีคือแบบมีวงจรกำเนิดเสียง

## มีขั้ว

ทั้งสองแบบมีขั้ว ขายาวคือขั้วบวก ตัวถังมักมีเครื่องหมายบวกกำกับที่ด้านบน ต่อกลับขั้วจะไม่ดัง

## แบบมีวงจรกำเนิดเสียง

```cpp
const int BUZZER_PIN = 14;

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);
}

void beep(int times) {
  for (int i = 0; i < times; i++) {
    digitalWrite(BUZZER_PIN, HIGH);
    delay(100);
    digitalWrite(BUZZER_PIN, LOW);
    delay(100);
  }
}
```

## แบบไม่มีวงจรกำเนิดเสียง

ต้องป้อนสัญญาณสี่เหลี่ยมที่ความถี่ที่ต้องการ บน ESP32 ไลบรารี Arduino ไม่มี `tone()` ให้ใช้
ตัวสร้าง PWM ในตัวชิปแทน

```cpp
const int BUZZER_PIN = 14;
const int CHANNEL = 0;

void setup() {
  ledcSetup(CHANNEL, 2000, 8);
  ledcAttachPin(BUZZER_PIN, CHANNEL);
}

void playTone(int frequency, int durationMs) {
  ledcWriteTone(CHANNEL, frequency);
  delay(durationMs);
  ledcWriteTone(CHANNEL, 0);   // ต้องสั่งหยุด ไม่งั้นจะดังค้าง
}

void alarm() {
  playTone(880, 200);
  playTone(660, 200);
}
```

ความถี่ที่ดังที่สุดของบัซเซอร์แบบเพียโซอยู่ราว 2–4 kHz ความถี่ต่ำกว่า 500 Hz จะเบามากจนแทบ
ไม่ได้ยิน แม้ค่าที่สั่งจะถูกต้อง

## กระแสและความดัง

บัซเซอร์กินราว 30 mA ซึ่งขา GPIO จ่ายได้ แต่ความดังจะน้อยกว่าที่ควรเพราะแรงดัน 3.3 V
ถ้าต้องการดังกว่านี้ให้ขับผ่านทรานซิสเตอร์ที่ไฟ 5 V

## ปัญหาที่พบบ่อย

- **เงียบสนิท** ใช้แบบไม่มีวงจรกำเนิดเสียงแต่สั่งด้วย `digitalWrite` หรือต่อกลับขั้ว
- **ดังค้างไม่หยุด** ลืมสั่งความถี่เป็น 0 หลังเล่นเสร็จ
- **เสียงเบามาก** ความถี่ต่ำเกินไป หรือแรงดันไม่พอ
- **มีเสียงคลิกแทนเสียงต่อเนื่อง** แบบไม่มีวงจรกำเนิดเสียงได้รับแค่การเปลี่ยนสถานะครั้งเดียว
