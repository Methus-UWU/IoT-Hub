## ภาพรวม

บอร์ดสีแดงที่มีลายทองแดงเปลือยสิบเส้น เส้นเว้นเส้นต่อกับรางซ้ายและรางขวา เมื่อน้ำเชื่อมระหว่าง
สองรางจะเปิดทรานซิสเตอร์บนบอร์ด ยิ่งลายจมน้ำมาก ค่าที่ขา `S` ยิ่งสูง

เป็นตัว **บอกระดับ** ไม่ใช่ตัว **วัดความลึก** ค่าที่ได้ไม่เป็นเชิงเส้นกับความลึก และเปลี่ยนตามแร่ธาตุ
ในน้ำ ใช้ได้ดีกับคำถามแบบ "น้ำถึงจุดนี้หรือยัง"

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| แรงดัน | 3–5 V |
| กระแส | ต่ำกว่า 20 mA |
| เอาต์พุต | แอนะล็อก 0 ถึงราว 70% ของแรงดันไฟเลี้ยง |
| ความยาวส่วนวัด | ราว 40 mm |

## ลายทองแดงกร่อนถ้าจ่ายไฟค้าง

ไฟฟ้ากระแสตรงที่ไหลผ่านน้ำทำให้ลายทองแดงสึกกร่อน ถ้าจ่ายไฟทิ้งไว้ในน้ำ ลายจะดำและค่าจะเพี้ยน
ภายในไม่กี่สัปดาห์ จ่ายไฟเฉพาะตอนอ่านค่าด้วยขา GPIO

```cpp
const int LEVEL_PIN = 34;        // ต้องเป็นขา ADC1
const int LEVEL_POWER_PIN = 27;  // จ่ายไฟให้ขา +

void setup() {
  pinMode(LEVEL_POWER_PIN, OUTPUT);
  digitalWrite(LEVEL_POWER_PIN, LOW);
}

int readLevel() {
  digitalWrite(LEVEL_POWER_PIN, HIGH);
  delay(10);
  int value = analogRead(LEVEL_PIN);
  digitalWrite(LEVEL_POWER_PIN, LOW);
  return value;
}
```

เซนเซอร์กินกระแสไม่ถึง 20 mA จึงจ่ายจากขา GPIO ได้

## ใช้เป็นเกณฑ์ ไม่ใช่ตัวเลขความลึก

วัดค่าที่ระดับที่สนใจจริง เช่น ตอนน้ำแห้ง ตอนน้ำครึ่งแผ่น และตอนน้ำเต็มแผ่น แล้วใช้ค่าเหล่านั้น
เป็นเกณฑ์ ถ้าต้องการความลึกเป็นเซนติเมตร ให้ใช้เซนเซอร์อัลตราโซนิกวัดจากปากถังแทน

## การติดตั้ง

ติดในแนวดิ่ง ให้ขาต่ออยู่ด้านบนเสมอ ส่วนที่มีชิ้นส่วนและขาต่อไม่กันน้ำ ห้ามให้น้ำขึ้นถึง
ในถังที่มีคลื่นหรือน้ำไหล ค่าจะแกว่ง ให้อ่านหลายครั้งแล้วเฉลี่ย

## ปัญหาที่พบบ่อย

- **ค่าสูงแม้ยกขึ้นจากน้ำแล้ว** มีหยดน้ำค้างเชื่อมระหว่างลาย เช็ดให้แห้งหรือรอให้แห้ง
- **ค่าลดลงเรื่อย ๆ ทั้งที่ระดับน้ำเท่าเดิม** ลายทองแดงกร่อน เปลี่ยนตัวใหม่และจ่ายไฟเฉพาะตอนอ่าน
- **น้ำกลั่นให้ค่าต่ำมาก** น้ำบริสุทธิ์นำไฟฟ้าได้น้อย เซนเซอร์ชนิดนี้ต้องอาศัยแร่ธาตุในน้ำ
