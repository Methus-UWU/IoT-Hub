## ภาพรวม

จอแสดงตัวอักษรที่ใช้ชิปควบคุม HD44780 หรือชิปที่เข้ากันได้ จอมีหน่วยความจำตัวอักษรในตัว
สั่งด้วยรหัสตัวอักษรแล้วจอวาดให้เอง จึงไม่ต้องส่งภาพทีละจุด

## รุ่นที่ระบบรองรับ

| รุ่น | ขนาด | การเชื่อมต่อ | ขาที่ใช้ |
| --- | --- | --- | --- |
| LCD1602 แบบขนาน | 16 ตัว 2 บรรทัด | ขาข้อมูลตรง | 6 ขา |
| LCD1602 + PCF8574 | 16 ตัว 2 บรรทัด | I2C | 2 ขา |
| LCD2004 แบบขนาน | 20 ตัว 4 บรรทัด | ขาข้อมูลตรง | 6 ขา |
| LCD2004 + PCF8574 | 20 ตัว 4 บรรทัด | I2C | 2 ขา |

แบบ I2C คือจอแบบขนานที่มีบอร์ดแปลงบัดกรีติดหลังจอ ตัวจอเหมือนกันทุกประการ

## แบบ I2C

ต่อสี่เส้น: `VCC` ไป 5 V, `GND` ไปกราวด์, `SDA` และ `SCL` ไปขา I2C ของบอร์ด บน ESP32
ขาปริยายคือ GPIO 21 สำหรับ SDA และ GPIO 22 สำหรับ SCL

แอดเดรสต่างกันตามผู้ผลิต ที่พบคือ `0x27` และ `0x3F` ถ้าจอไม่ขึ้นข้อความให้สแกนก่อน

```cpp
#include <Wire.h>

void scanI2c() {
  Wire.begin();
  for (byte address = 1; address < 127; address++) {
    Wire.beginTransmission(address);
    if (Wire.endTransmission() == 0) {
      Serial.printf("พบอุปกรณ์ที่ 0x%02X\n", address);
    }
  }
}
```

```cpp
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Temp: 25.4 C");
}
```

## แบบขนาน

ต่อในโหมด 4 บิตซึ่งใช้ขาน้อยกว่า: `RS`, `E`, `D4`, `D5`, `D6`, `D7` รวมหกขา ส่วน `RW`
ต่อลงกราวด์ค้างไว้เพราะเราไม่ต้องอ่านค่ากลับจากจอ

**ขา `V0` ต้องต่อผ่านตัวต้านทานปรับค่า 10 kΩ** ปลายหนึ่งไป 5 V อีกปลายไปกราวด์ แล้วแกน
กลางเข้า `V0` ถ้าไม่มีตัวนี้จอจะว่างเปล่าหรือแสดงเป็นแถวสี่เหลี่ยมทึบทั้งที่วงจรถูกต้องแล้ว

## จอ 5 V กับบอร์ด 3.3 V

จอทำงานที่ 5 V และ ESP32 ส่งสัญญาณ 3.3 V ออกไป ส่วนใหญ่ใช้ได้เพราะจอถือว่า 3.3 V คือ
ลอจิกสูง แต่บางล็อตต้องใช้ 5 V จริง อาการคือจอติดไฟส่องหลังแต่ไม่มีตัวอักษร ถ้าเจอแบบนั้น
ให้จ่ายไฟจอที่ 5 V แล้วใช้ตัวแปลงระดับแรงดันที่สาย SDA/SCL

## ปัญหาที่พบบ่อย

- **จอสว่างแต่ว่างเปล่า** ยังไม่ได้ปรับความเข้มที่ขา `V0` หรือแอดเดรส I2C ผิด
- **แสดงเป็นสี่เหลี่ยมทึบแถวบน** จอได้ไฟแต่ยังไม่ได้รับคำสั่งเริ่มต้น ตรวจสาย `E` และ `RS`
- **ตัวอักษรเพี้ยนหลังใช้ไปสักพัก** ไฟเลี้ยงไม่นิ่ง ใส่ตัวเก็บประจุ 100 µF คร่อมไฟจอ
- **ภาษาไทยไม่ขึ้น** จอเก็บเฉพาะชุดตัวอักษรในตัว ไม่มีภาษาไทย ถ้าต้องแสดงภาษาไทยให้ใช้
  จอ OLED ซึ่งวาดทีละจุดได้
