## ภาพรวม

ไดโอดเปล่งแสง นำกระแสได้ทางเดียวและเปล่งแสงเมื่อมีกระแสไหลผ่าน จุดสำคัญคือ LED ไม่จำกัด
กระแสด้วยตัวเอง แรงดันที่เกินค่าตกคร่อมเพียงเล็กน้อยทำให้กระแสพุ่งจนหลอดพัง จึงต้องมีตัวต้านทาน
อนุกรมเสมอ

## แรงดันตกคร่อมตามสี

| สี | แรงดันตกคร่อม | กระแสใช้งาน |
| --- | --- | --- |
| แดง | 1.8–2.2 V | 20 mA |
| เหลือง | 2.0–2.2 V | 20 mA |
| เขียว | 2.0–3.0 V | 20 mA |
| น้ำเงิน | 2.8–3.4 V | 20 mA |
| ขาว | 3.0–3.4 V | 20 mA |

## คำนวณตัวต้านทาน

สูตรคือ `R = (แรงดันจ่าย − แรงดันตกคร่อม) ÷ กระแสที่ต้องการ`

LED แดงกับขา GPIO 3.3 V ของ ESP32 ที่กระแส 10 mA จะได้ `(3.3 − 2.0) ÷ 0.01 = 130 Ω`
เลือกค่ามาตรฐานที่ใกล้และสูงกว่าคือ 150 Ω

| สถานการณ์ | ค่าที่ใช้ได้ |
| --- | --- |
| LED แดง/เหลือง/เขียว กับ 3.3 V | 150–220 Ω |
| LED แดง/เหลือง/เขียว กับ 5 V | 220–330 Ω |
| LED น้ำเงิน/ขาว กับ 3.3 V | 47–100 Ω |
| LED น้ำเงิน/ขาว กับ 5 V | 150–220 Ω |

ค่า 220 Ω ใช้ได้กับเกือบทุกกรณีถ้าไม่ต้องการความสว่างสูงสุด สว่างน้อยลงแต่ไม่มีอะไรพัง

## แยกขั้ว

ขายาวคือขั้วบวก ต่อไปทางไฟบวก ขาสั้นคือขั้วลบ ต่อลงกราวด์ ถ้าขาถูกตัดจนยาวเท่ากันแล้ว
ให้ดูขอบตัวถัง ด้านที่ตัดเรียบคือขั้วลบ ต่อกลับขั้วแล้ว LED จะไม่ติด แต่ไม่พังที่แรงดันระดับนี้

## กระแสรวมของบอร์ด

ขา GPIO ของ ESP32 จ่ายได้ 40 mA ต่อขา แต่รวมทุกขาไม่ควรเกิน 200 mA ต่อ LED แปดดวง
ดวงละ 20 mA แล้วสั่งติดพร้อมกันคือ 160 mA ซึ่งใกล้เพดานมาก งานที่ต้องการ LED หลายดวง
ควรผ่านชิฟต์รีจิสเตอร์ 74HC595 หรือทรานซิสเตอร์

## หรี่แสงด้วย PWM

```cpp
const int LED_PIN = 2;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void fade() {
  for (int level = 0; level <= 255; level++) {
    analogWrite(LED_PIN, level);
    delay(5);
  }
}
```

สายตาคนรับรู้ความสว่างแบบไม่เชิงเส้น ค่าจาก 0 ถึง 128 จึงดูสว่างขึ้นเยอะ ส่วน 128 ถึง 255
แทบไม่ต่างกัน ถ้าต้องการให้ดูค่อย ๆ สว่างสม่ำเสมอ ให้ยกกำลังสองค่าที่ตั้งไว้ก่อนส่งออก

## ปัญหาที่พบบ่อย

- **ไม่ติด** ต่อกลับขั้ว หรือลืมตัวต้านทานแล้วหลอดพังไปแล้ว
- **สว่างจ้าแล้วดับถาวรในไม่กี่วินาที** ต่อตรงเข้าขา GPIO โดยไม่มีตัวต้านทาน
- **ติดจาง ๆ ทั้งที่สั่งดับ** ขา GPIO ถูกตั้งเป็นอินพุตแล้วลอย ให้ตั้งเป็นเอาต์พุตและเขียนค่าต่ำ
- **LED หลายดวงสว่างไม่เท่ากัน** ต่ออนุกรมกันแล้วใช้ตัวต้านทานตัวเดียว ต้องแยกตัวต้านทาน
  ให้แต่ละดวง
