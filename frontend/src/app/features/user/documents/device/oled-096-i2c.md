## ภาพรวม

จอ OLED ขนาด 0.96 นิ้ว ความละเอียด 128×64 จุด ควบคุมด้วยชิป SSD1306 ผ่าน I2C แต่ละจุด
เปล่งแสงเอง จึงไม่มีไฟส่องหลังและจุดสีดำคือจุดที่ดับสนิท ให้ความคมชัดสูงกว่าจอ LCD มาก

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| ความละเอียด | 128 × 64 จุด |
| แรงดัน | 3.3–5 V |
| กระแส | 10–20 mA ขึ้นกับจำนวนจุดที่ติด |
| แอดเดรส I2C | `0x3C` ปกติ บางรุ่นเป็น `0x3D` |
| มุมมอง | กว้างเกือบ 180 องศา |

## หน่วยความจำที่ต้องเผื่อ

ไลบรารีต้องเก็บภาพทั้งจอไว้ในแรมก่อนส่งออก ขนาดคือ `128 × 64 ÷ 8 = 1024` ไบต์ บน ESP32
ไม่เป็นปัญหา แต่บน Arduino Uno ซึ่งมีแรมทั้งหมด 2048 ไบต์ นี่คือครึ่งหนึ่งของทั้งบอร์ด ถ้าใช้กับ
Uno แล้วโปรแกรมทำงานผิดปกติแบบสุ่ม สาเหตุมักคือแรมหมด

## ตัวอย่างโค้ด

```cpp
#include <Adafruit_SSD1306.h>

Adafruit_SSD1306 display(128, 64, &Wire, -1);

void setup() {
  // -1 คือไม่มีขารีเซ็ต จอส่วนใหญ่ไม่มีขานี้ต่อออกมา
  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    Serial.println("ไม่พบจอที่แอดเดรส 0x3C");
    return;
  }
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);
}

void showTemperature(float celsius) {
  display.clearDisplay();
  display.setCursor(0, 0);
  display.print("อุณหภูมิ");           // ต้องใช้ฟอนต์ที่มีภาษาไทยจึงจะขึ้น
  display.setTextSize(2);
  display.setCursor(0, 20);
  display.print(celsius, 1);
  display.print(" C");
  display.display();                   // ไม่เรียกบรรทัดนี้จอจะไม่เปลี่ยน
}
```

ต้องเรียก `display.display()` ทุกครั้งหลังวาดเสร็จ คำสั่งวาดทั้งหมดแก้แค่ภาพในแรม ไม่ได้ส่งไปจอ

## การเบิร์นอิน

จุดที่ติดค้างสว่างนาน ๆ จะจางลงถาวร หน้าจอที่แสดงข้อความเดิมตลอด 24 ชั่วโมงจะเห็นรอยภายใน
ไม่กี่เดือน ถ้าต้องเปิดค้าง ให้สลับหน้าจอเป็นระยะ หรือเลื่อนตำแหน่งข้อความทีละไม่กี่จุด

## ภาษาไทย

จอวาดทีละจุดจึงแสดงภาษาไทยได้ แต่ต้องมีฟอนต์ไทยฝังในโปรแกรม ฟอนต์ปริยายของไลบรารี
มีเฉพาะอักษรละติน สระบนล่างของไทยต้องใช้ฟอนต์ที่จัดตำแหน่งมาให้แล้ว ไม่งั้นสระจะซ้อนผิดที่

## ปัญหาที่พบบ่อย

- **จอไม่ติดเลย** แอดเดรสผิด ลอง `0x3D` หรือสแกนบัส I2C ก่อน
- **วาดแล้วจอไม่เปลี่ยน** ลืมเรียก `display.display()`
- **จอค้างภาพเดิมหลังบอร์ดรีสตาร์ต** จอไม่ได้ถูกรีเซ็ตไปด้วย ให้ `clearDisplay()` ใน `setup()`
- **ภาพกะพริบตอนอัปเดตบ่อย** วาดใหม่ทั้งจอทุกครั้ง ให้ลดความถี่ลงเหลือ 2–4 ครั้งต่อวินาที
