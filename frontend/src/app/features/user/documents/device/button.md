## ภาพรวม

สวิตช์สัมผัสชั่วขณะขนาด 6×6 มม. ต่อวงจรเฉพาะตอนกดค้าง ปล่อยแล้วสปริงดันกลับมาตัดวงจร
ตัวถังมีสี่ขา แต่เป็นสองคู่ที่ต่อถึงกันภายในอยู่แล้ว

## ขาคู่ไหนต่อถึงกัน

ขาที่อยู่ **ตรงข้ามกัน** คือขาที่สวิตช์ตัดต่อ ส่วนขาที่อยู่ข้างเดียวกันต่อถึงกันตลอดเวลาไม่ว่าจะกด
หรือไม่ ถ้าต่อผิดคู่ วงจรจะเหมือนมีสายลัดถาวรและปุ่มไม่มีผลอะไรเลย

เสียบคร่อมร่องกลางของเบรดบอร์ดจะได้คู่ที่ถูกต้องเสมอ

## ต้องมีตัวต้านทานพูลอัปหรือพูลดาวน์

ขา GPIO ที่ไม่ได้ต่ออะไรจะ "ลอย" และอ่านค่าได้แบบสุ่มตามสัญญาณรบกวนรอบตัว ปุ่มที่ต่อกับ
กราวด์อย่างเดียวจึงอ่านค่าไม่ได้ตอนไม่กด ต้องมีตัวต้านทานดึงขาไปทางใดทางหนึ่ง

วิธีที่ง่ายที่สุดคือใช้ตัวต้านทานพูลอัปในตัวชิป ไม่ต้องต่ออะไรเพิ่ม

```cpp
const int BUTTON_PIN = 4;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
}

bool isPressed() {
  // พูลอัปทำให้ค่าปกติเป็น HIGH และกดแล้วเป็น LOW
  return digitalRead(BUTTON_PIN) == LOW;
}
```

ต่อขาหนึ่งของปุ่มเข้า GPIO อีกขาลงกราวด์ ไม่ต้องมีตัวต้านทานภายนอก

บน ESP32 ขา GPIO 34–39 **ไม่มีตัวต้านทานพูลอัปในตัว** ถ้าใช้ขาเหล่านี้ต้องต่อตัวต้านทาน
10 kΩ ภายนอกเอง

## หน้าสัมผัสสั่น

หน้าสัมผัสโลหะกระเด้งหลายครั้งในช่วงไม่กี่มิลลิวินาทีตอนแตะกัน โค้ดที่นับจำนวนการกดจะนับได้
สามถึงห้าครั้งจากการกดจริงครั้งเดียว ต้องกรองด้วยเวลา

```cpp
const unsigned long DEBOUNCE_MS = 50;
unsigned long lastChange = 0;
bool lastState = HIGH;

bool pressedOnce() {
  bool state = digitalRead(BUTTON_PIN);
  if (state == lastState) return false;
  if (millis() - lastChange < DEBOUNCE_MS) return false;

  lastChange = millis();
  lastState = state;
  return state == LOW;   // นับเฉพาะขอบขาลง คือจังหวะที่เพิ่งกด
}
```

ค่า 50 มิลลิวินาทีครอบคลุมสวิตช์เกือบทุกตัว ถ้าตั้งสูงกว่า 200 ผู้ใช้จะรู้สึกว่าปุ่มตอบสนองช้า

## กดค้างกับกดสั้น

แยกได้จากเวลาที่ปุ่มอยู่ในสถานะถูกกด จับเวลาตอนขอบขาลง แล้ววัดตอนขอบขาขึ้น เกิน 800
มิลลิวินาทีถือเป็นกดค้าง ต่ำกว่านั้นเป็นกดสั้น

## ปัญหาที่พบบ่อย

- **อ่านค่าได้สุ่มตอนไม่กด** ขาลอย ใช้ `INPUT_PULLUP`
- **กดหนึ่งครั้งนับได้หลายครั้ง** ยังไม่ได้กรองหน้าสัมผัสสั่น
- **ปุ่มไม่มีผลเลย** ต่อผิดคู่ขา ใช้ขาที่อยู่ตรงข้ามกัน
- **ปุ่มทำงานเองเมื่อมอเตอร์เริ่มหมุน** สัญญาณรบกวนเข้าสายปุ่ม ให้ใช้สายสั้นลงหรือใส่ตัวเก็บ
  ประจุ 100 nF คร่อมปุ่ม
