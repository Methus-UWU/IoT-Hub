## ภาพรวม

ตัวต้านทานปรับค่าได้แบบหมุน ภายในเป็นแถบตัวต้านทานที่มีหน้าสัมผัสเลื่อนไปตามการหมุนแกน
ต่อครบสามขาจะได้ตัวแบ่งแรงดันที่ปรับได้ ซึ่งเป็นวิธีใช้งานปกติ

## การต่อ

| ขา | ต่อไปที่ |
| --- | --- |
| ขาริมด้านหนึ่ง | ไฟบวก 3.3 V |
| ขากลาง | ขา ADC ของบอร์ด |
| ขาริมอีกด้าน | กราวด์ |

สลับขาริมสองข้างจะทำให้ทิศทางการหมุนกลับด้าน ไม่ได้ทำให้เสียหาย

**ต่อไฟบวกที่ 3.3 V ไม่ใช่ 5 V** เมื่อใช้กับ ESP32 เพราะขา ADC รับได้สูงสุด 3.3 V

## อ่านค่า

```cpp
const int POT_PIN = 34;   // ต้องเป็นขา ADC1 ถ้าใช้ Wi-Fi ด้วย

int brightnessPercent() {
  int raw = analogRead(POT_PIN);       // ESP32 ให้ 0–4095
  return map(raw, 0, 4095, 0, 100);
}
```

Arduino ให้ค่า 0–1023 ส่วน ESP32 ให้ 0–4095 โค้ดที่ย้ายข้ามบอร์ดต้องแก้ตัวเลขนี้

## ค่าที่อ่านได้ไม่นิ่ง

ค่าจาก ADC สั่นอยู่ไม่กี่หน่วยตลอดเวลา แม้ไม่ได้หมุนแกนเลย ถ้าเอาค่านี้ไปสั่งงานโดยตรง อุปกรณ์
ปลายทางจะกระตุกตลอด แก้ด้วยการยอมรับค่าใหม่เฉพาะเมื่อต่างจากค่าเดิมมากพอ

```cpp
int lastValue = 0;

int stableRead() {
  int raw = analogRead(POT_PIN);
  if (abs(raw - lastValue) > 30) {   // ต่ำกว่า 30 ถือว่าเป็นสัญญาณรบกวน
    lastValue = raw;
  }
  return lastValue;
}
```

## ADC ของ ESP32 ไม่เป็นเชิงเส้น

ค่าที่อ่านได้ในช่วงต่ำกว่า 0.1 V และสูงกว่า 3.1 V จะอิ่มตัว หมุนสุดสองปลายแล้วค่าไม่ถึง 0 หรือ
ไม่ถึง 4095 พอดี ถ้างานต้องการช่วงเต็มจริง ๆ ให้วัดค่าที่ปลายทั้งสองแล้วใช้ค่านั้นใน `map`

## ใช้ปรับความเข้มจอ LCD

จอ LCD แบบขนานต้องใช้ตัวต้านทานปรับค่า 10 kΩ ที่ขา `V0` โดยต่อขาริมสองข้างระหว่าง 5 V
กับกราวด์ แล้วขากลางเข้า `V0` ในกรณีนี้ไม่ได้ต่อกับบอร์ดเลย เป็นการปรับด้วยมือล้วน

## ปัญหาที่พบบ่อย

- **ค่าไม่เปลี่ยนตามการหมุน** ต่อแค่สองขา ต้องต่อครบสามขา
- **ค่ากระโดดสุดขั้วเป็นบางครั้ง** หน้าสัมผัสภายในสกปรกหรือสึก พบบ่อยในตัวที่ใช้มานาน
- **หมุนสุดแล้วค่าไม่ถึงศูนย์** ข้อจำกัดของ ADC ปรับช่วงใน `map` แทน
- **ค่าเพี้ยนเมื่อเปิด Wi-Fi** ต่อขากลางเข้าขา ADC2 ให้ย้ายไป ADC1
