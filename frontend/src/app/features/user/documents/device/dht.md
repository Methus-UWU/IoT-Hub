## ภาพรวม

เซนเซอร์วัดอุณหภูมิและความชื้นที่รวมตัวตรวจจับกับวงจรแปลงสัญญาณไว้ในตัวถังเดียว ส่งค่าที่
แปลงเป็นตัวเลขแล้วกลับมาทางสายสัญญาณเส้นเดียว จึงไม่ต้องใช้ขาแอนะล็อกและไม่ต้องปรับเทียบ

## เปรียบเทียบสองรุ่น

| หัวข้อ | DHT11 | DHT22 |
| --- | --- | --- |
| ช่วงวัดอุณหภูมิ | 0 ถึง 50 °C | −40 ถึง 80 °C |
| ความคลาดเคลื่อน | ±2 °C | ±0.5 °C |
| ความละเอียด | 1 °C | 0.1 °C |
| ช่วงวัดความชื้น | 20–90 %RH | 0–100 %RH |
| ความคลาดเคลื่อนความชื้น | ±5 %RH | ±2 %RH |
| อ่านค่าได้ถี่สุด | 1 ครั้งต่อ 1 วินาที | 1 ครั้งต่อ 2 วินาที |
| สีตัวถัง | ฟ้า | ขาว |

DHT11 วัดอุณหภูมิติดลบไม่ได้เลย งานที่ต้องวัดในตู้เย็นหรือกลางแจ้งหน้าหนาวต้องใช้ DHT22

## การต่อวงจร

ตัวเซนเซอร์แบบสี่ขา ขาที่สามนับจากซ้ายไม่ได้ต่ออะไรภายใน ปล่อยลอยไว้

```
DHT          บอร์ด
VCC   ────   3V3 หรือ 5V
DATA  ────   GPIO ที่เลือก
NC           ไม่ต่อ
GND   ────   GND
```

**ต้องมีตัวต้านทานพูลอัป 4.7 kΩ ระหว่างขา DATA กับ VCC เสมอ** บอร์ดแบบสามขาที่ขายกันทั่วไป
มีตัวต้านทานนี้ติดมาบนแผ่นแล้ว ถ้าใช้ตัวเซนเซอร์เปล่าต้องต่อเอง ไม่มีตัวนี้แล้วจะอ่านค่าไม่ได้เลย
หรือได้ค่าขยะสลับกับค่าถูกต้อง

## ตัวอย่างโค้ด

```cpp
#include <DHT.h>

#define DHT_PIN 4
DHT dht(DHT_PIN, DHT22);

unsigned long lastRead = 0;
float temperature = NAN;
float humidity = NAN;

void setup() {
  Serial.begin(115200);
  dht.begin();
}

void loop() {
  if (millis() - lastRead >= 2000) {
    lastRead = millis();
    float t = dht.readTemperature();
    float h = dht.readHumidity();
    if (isnan(t) || isnan(h)) {
      Serial.println("อ่านค่าไม่สำเร็จ");
      return;
    }
    temperature = t;
    humidity = h;
  }
}
```

ต้องตรวจ `isnan` ทุกครั้ง ไลบรารีคืนค่า `NAN` เมื่ออ่านไม่สำเร็จ ถ้าเอาค่าไปคำนวณต่อโดยไม่ตรวจ
ผลลัพธ์ทั้งสายจะกลายเป็น `NAN` ตามไปด้วย

## ปัญหาที่พบบ่อย

- **อ่านได้ `NAN` ตลอด** ไม่มีตัวต้านทานพูลอัป หรือสายยาวเกิน 20 เมตร
- **ค่าถูกสลับกับค่าขยะ** อ่านถี่เกินกำหนด ให้เว้นระยะตามตารางข้างบน
- **อุณหภูมิสูงกว่าความจริง 2–3 °C** เซนเซอร์อยู่ใกล้ตัวควบคุมแรงดันของบอร์ดที่ร้อน ให้ย้าย
  ออกห่างด้วยสายต่อ
- **ความชื้นค้างที่ 99 %RH** มีน้ำเกาะที่ตัวตรวจจับ ต้องรอให้แห้งสนิท ตัวเซนเซอร์กันน้ำไม่ได้
