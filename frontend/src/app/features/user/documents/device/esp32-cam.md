## ภาพรวม

ESP32 พร้อมกล้อง OV2640 และช่องเสียบ microSD บนบอร์ดเดียว ใช้ทำกล้องดูสัตว์เลี้ยง กล้อง
ตรวจจับความเคลื่อนไหว หรือสตรีมวิดีโอผ่าน Wi-Fi

บอร์ดนี้ใช้ยากกว่า DevKit อย่างเห็นได้ชัด เพราะไม่มีชิป USB ในตัวและขาที่ใช้ได้เหลือน้อยมาก

## ไม่มีพอร์ต USB

ต้องใช้ตัวแปลง USB เป็น TTL แยกต่างหาก และต้องต่อ `GPIO 0` ลงกราวด์ทุกครั้งที่จะอัปโหลด

```
ตัวแปลง USB-TTL     ESP32-CAM
5V            ────  5V
GND           ────  GND
TX            ────  U0R
RX            ────  U0T
                    GPIO 0 ── GND  (เฉพาะตอนอัปโหลด)
```

ลำดับที่ใช้ได้: ต่อ `GPIO 0` ลงกราวด์ จ่ายไฟ กดปุ่มรีเซ็ต แล้วสั่งอัปโหลด เมื่อเสร็จให้ถอดสาย
`GPIO 0` ออกแล้วกดรีเซ็ตอีกครั้ง ไม่ถอดสายนี้ออกบอร์ดจะไม่รันโปรแกรมที่เพิ่งอัปโหลดไป

## ต้องจ่ายไฟ 5 V ไม่ใช่ 3.3 V

กล้องกินกระแสสูง โดยเฉพาะตอนเปิดไฟแฟลช การจ่ายจากขา 3.3 V ของตัวแปลง USB-TTL แทบ
ไม่เคยพอ อาการคือบอร์ดรีสตาร์ตวนพร้อมข้อความ `Brownout detector was triggered` หรือ
`Camera probe failed` ให้จ่าย 5 V จากแหล่งที่จ่ายได้อย่างน้อย 500 mA

## ขาที่เหลือให้ใช้มีน้อยมาก

กล้องยึดขาไปเกือบหมด ขาที่เหลือใช้ได้จริงคือ

| ขา | หมายเหตุ |
| --- | --- |
| `GPIO 0` | ใช้ได้หลังบูตแล้ว แต่ต้องไม่ต่ออะไรที่ดึงลงต่ำตอนบูต |
| `GPIO 2` | ใช้ร่วมกับ microSD |
| `GPIO 4` | ต่อกับไฟแฟลช LED บนบอร์ด |
| `GPIO 12, 13, 14, 15` | ใช้ร่วมกับ microSD |
| `GPIO 16` | ว่าง ใช้ได้อิสระ |

ถ้าไม่ใช้ microSD จะได้ขา 2, 12, 13, 14, 15 กลับมาใช้ ถ้าใช้ microSD เหลือแค่ `GPIO 16`
จริง ๆ งานที่ต้องต่อเซนเซอร์หลายตัวควรใช้ ESP32 ตัวอื่นแล้วให้บอร์ดนี้ทำหน้าที่กล้องอย่างเดียว

## ไฟแฟลชสว่างมาก

LED ที่ `GPIO 4` เป็นดวงกำลังสูง ไม่ใช่ LED บอกสถานะ การเปิดค้างนานทำให้บอร์ดร้อนจัด ให้
เปิดเฉพาะช่วงถ่ายภาพ

```cpp
const int FLASH_PIN = 4;

void captureWithFlash() {
  digitalWrite(FLASH_PIN, HIGH);
  delay(100);
  camera_fb_t* frame = esp_camera_fb_get();
  digitalWrite(FLASH_PIN, LOW);
  // ต้องคืนบัฟเฟอร์ทุกครั้ง ไม่งั้นหน่วยความจำหมดหลังถ่ายไม่กี่รูป
  esp_camera_fb_return(frame);
}
```

การลืม `esp_camera_fb_return` คือสาเหตุที่บอร์ดค้างหลังถ่ายไปสิบกว่ารูป

## ความละเอียดกับหน่วยความจำ

บอร์ดที่มีชิป PSRAM ถ่ายได้ถึง 1600×1200 ส่วนบอร์ดที่ไม่มีจำกัดอยู่ราว 800×600 ถ้าตั้ง
ความละเอียดสูงกว่าที่หน่วยความจำรองรับ กล้องจะเริ่มต้นไม่สำเร็จตั้งแต่แรก

## ปัญหาที่พบบ่อย

- **`Camera probe failed with error 0x105`** ไฟไม่พอ หรือสายแพกล้องเสียบไม่แน่น
- **อัปโหลดสำเร็จแต่ไม่ทำงาน** ลืมถอดสาย `GPIO 0` ออกจากกราวด์
- **บอร์ดร้อนจัด** ปกติสำหรับบอร์ดนี้ แต่ถ้าร้อนจนแตะไม่ได้ให้ตรวจว่าไฟแฟลชติดค้างหรือไม่
- **ภาพค้างหรือบอร์ดรีสตาร์ตหลังถ่ายหลายรูป** ไม่ได้คืนบัฟเฟอร์เฟรม
