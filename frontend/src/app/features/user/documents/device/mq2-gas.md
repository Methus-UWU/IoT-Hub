> **คำเตือน** เซนเซอร์ตัวนี้ไม่ใช่อุปกรณ์นิรภัยที่ผ่านการรับรอง ห้ามใช้เป็นเครื่องเตือนแก๊สรั่ว
> ตัวเดียวในที่ที่ชีวิตขึ้นอยู่กับมัน ใช้เป็นงานทดลองหรือเป็นชั้นเสริมจากเครื่องเตือนที่ได้มาตรฐาน

## ภาพรวม

ตัวตรวจจับเป็นดีบุกไดออกไซด์ที่ถูกทำให้ร้อนด้วยไส้ในตัว เมื่อโมเลกุลแก๊สติดไฟมาสัมผัสผิวที่ร้อน
ค่าความต้านทานจะลดลง วงจรอ่านความต้านทานนั้นออกมาเป็นแรงดัน

ตรวจจับได้: แก๊สหุงต้ม โพรเพน มีเทน ไฮโดรเจน แอลกอฮอล์ และควัน **แยกชนิดแก๊สไม่ได้**
ค่าที่อ่านได้บอกแค่ว่ามีแก๊สติดไฟมากขึ้นเท่านั้น

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| แรงดัน | 5 V สำหรับไส้ร้อน |
| กระแส | ราว 150 mA ตลอดเวลา |
| ช่วงตรวจจับ | 300–10000 ppm |
| เวลาอุ่นเครื่องก่อนอ่านค่า | 20 วินาที ถึง 3 นาที |
| เวลาเผาไส้ครั้งแรก | 24–48 ชั่วโมง |

## กินไฟมากกว่าที่คิด

ไส้ร้อนกิน 150 mA ตลอดเวลาที่จ่ายไฟ ซึ่งมากกว่าเซนเซอร์อื่นในคลังนี้หลายเท่า และเป็นเหตุผลที่
จ่ายจากขา `5V` ของบอร์ดพัฒนาโดยตรงมักไม่พอ อาการคือบอร์ดรีสตาร์ตเองหรือค่าที่อ่านได้ลอย

เซนเซอร์ตัวนี้ใช้กับงานที่ใช้ถ่านไม่ได้ในทางปฏิบัติ 150 mA ต่อเนื่องกินถ่าน AA สี่ก้อนหมดภายใน
ราวหนึ่งวัน

## ต้องเผาไส้ก่อนใช้ครั้งแรก

เซนเซอร์ใหม่จากโรงงานต้องจ่ายไฟทิ้งไว้ 24–48 ชั่วโมงก่อนใช้จริง เพื่อไล่สิ่งตกค้างบนผิวตัวตรวจจับ
ค่าที่อ่านได้ก่อนครบเวลานี้จะลอยลงเรื่อย ๆ และเชื่อถือไม่ได้ ถ้าเก็บไม่ได้ใช้นานหลายเดือน ต้องเผา
ซ้ำราวหนึ่งชั่วโมงก่อนใช้

## อ่านค่าและตั้งเกณฑ์

ค่าที่ได้เป็นค่าสัมพัทธ์ ไม่ใช่ ppm จริง การแปลงเป็น ppm ต้องปรับเทียบกับแก๊สที่ทราบความเข้มข้น
ซึ่งงานทั่วไปทำไม่ได้ วิธีที่ใช้ได้จริงคือวัดค่าพื้นฐานในอากาศสะอาดแล้วเตือนเมื่อค่าสูงกว่านั้นมาก

```cpp
const int MQ2_PIN = 34;      // ต้องเป็นขา ADC1
int baseline = 0;

void calibrate() {
  long total = 0;
  for (int i = 0; i < 100; i++) {
    total += analogRead(MQ2_PIN);
    delay(50);
  }
  baseline = total / 100;    // วัดในอากาศสะอาดเท่านั้น
}

bool gasDetected() {
  return analogRead(MQ2_PIN) > baseline * 1.5;
}
```

ต้องเรียก `calibrate()` หลังอุ่นเครื่องเสร็จแล้ว และต้องมั่นใจว่าอากาศตอนนั้นสะอาดจริง ไม่งั้น
ค่าพื้นฐานจะสูงเกินไปจนไม่เตือนอะไรเลย

## การติดตั้ง

แก๊สหุงต้มหนักกว่าอากาศจึงลอยลงต่ำ ติดเซนเซอร์ใกล้พื้น ส่วนมีเทนเบากว่าอากาศ ติดใกล้เพดาน
ตัวเซนเซอร์เองร้อนขณะทำงาน อย่าติดในที่อับที่ความร้อนสะสม

## ปัญหาที่พบบ่อย

- **ค่าลอยลงเรื่อย ๆ ในชั่วโมงแรก** ปกติ รอให้เสถียรก่อนปรับเทียบ
- **แจ้งเตือนเวลาทำอาหาร** ไอน้ำมันและแอลกอฮอล์ทำให้ค่าขึ้นได้จริง เซนเซอร์แยกไม่ออก
- **ค่าเปลี่ยนตามความชื้นในอากาศ** เป็นข้อจำกัดของเซนเซอร์ชนิดนี้
- **ตัวเซนเซอร์ร้อนจนจับไม่ได้** ปกติ ไส้ในทำงานที่อุณหภูมิสูง
