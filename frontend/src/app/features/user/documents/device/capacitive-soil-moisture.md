## ภาพรวม

แผ่นวัดเป็นทองแดงที่อยู่ใต้ชั้นเคลือบของ PCB ไม่มีโลหะสัมผัสดิน ความชื้นในดินเปลี่ยนค่าความจุ
ของแผ่นนี้ วงจรออสซิลเลเตอร์บนบอร์ดแปลงค่าความจุเป็นแรงดันออกที่ขา `AOUT`

ต่างจาก FC-28 ตรงที่ไม่มีขั้วโลหะเปลือย จึงไม่กร่อน ปักทิ้งไว้ในดินได้เป็นเดือน และไม่มีขาดิจิทัล
ไม่มีวงจรเปรียบเทียบ มีเอาต์พุตแอนะล็อกขาเดียว

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| แรงดัน | 3.3–5.5 V |
| กระแส | ราว 5 mA |
| เอาต์พุต | แอนะล็อก ราว 1.1–2.6 V เมื่อจ่าย 3.3 V |
| ขนาดบอร์ด | 98 × 23 mm |

## ค่าที่อ่านได้กลับด้านกับความชื้น

**ค่าสูง = ดินแห้ง ค่าต่ำ = ดินเปียก** เหมือน FC-28 แต่ช่วงแคบกว่าและไม่เคยแตะ 0 หรือแรงดันไฟเลี้ยง
จึงใช้ค่าปรับเทียบของ FC-28 ไม่ได้ ต้องวัดใหม่

```cpp
const int SOIL_PIN = 34;     // ต้องเป็นขา ADC1
const int AIR_VALUE = 3200;  // วัดตอนแผ่นอยู่ในอากาศ
const int WATER_VALUE = 1400; // วัดตอนจุ่มน้ำถึงเส้นสีขาว

int moisturePercent() {
  int raw = analogRead(SOIL_PIN);
  int percent = map(raw, AIR_VALUE, WATER_VALUE, 0, 100);
  return constrain(percent, 0, 100);
}
```

ค่าปรับเทียบต่างกันในแต่ละตัว ถ้าใช้หลายตัวต้องวัดแยกทุกตัว

## ปักไม่เกินเส้นสีขาว

เส้นสีขาวบนบอร์ดคือความลึกสูงสุด ส่วนที่อยู่เหนือเส้นมีวงจรที่ไม่กันน้ำ ถ้าดินหรือน้ำขึ้นมาถึง
ค่าจะเพี้ยนและวงจรพังได้ ถ้าติดตั้งกลางแจ้งให้หุ้มส่วนวงจรด้วยท่อหดหรือกล่องกันน้ำ

ขอบแผ่นที่ตัดจากโรงงานไม่มีชั้นเคลือบ ความชื้นซึมเข้าเนื้อ PCB ได้ช้า ๆ ทาน้ำยาเคลือบหรือยาทาเล็บ
ใสที่ขอบก่อนใช้งานระยะยาว

## บางล็อตใช้กับ 3.3 V ไม่ได้

บอร์ดรุ่นนี้ออกแบบให้ใช้ชิป TLC555 ซึ่งทำงานที่ 3.3 V ได้ บางล็อตใส่ NE555 มาแทน ซึ่งต้องการไฟ
ราว 4.5 V ขึ้นไป อาการคือต่อ 3.3 V แล้วค่าไม่ขยับเลย ให้ดูรหัสบนชิป ถ้าเป็น NE555 ต้องจ่าย 5 V
และต้องแบ่งแรงดันขา `AOUT` ก่อนเข้า ESP32

## การติดตั้ง

ปักในแนวดิ่ง ให้ดินแน่นรอบแผ่นทั้งสองด้าน ช่องอากาศรอบแผ่นทำให้ค่าสูงเหมือนดินแห้ง หลังปักเสร็จ
ให้รดน้ำเล็กน้อยให้ดินยุบตัวเข้าหาแผ่น

## ปัญหาที่พบบ่อย

- **ค่าไม่เปลี่ยนเลย** ชิปเป็น NE555 และจ่ายไฟแค่ 3.3 V หรือสายขาดที่ขั้วต่อ
- **ค่าเปลี่ยนเมื่อจับบอร์ด** มือเปลี่ยนค่าความจุ อ่านค่าตอนไม่มีอะไรแตะแผ่น
- **ค่าในกระถางต่างจากในแปลงมาก** ดินต่างชนิดให้ค่าต่างกัน ปรับเทียบกับดินที่ใช้จริง
- **ค่ากระโดดหลังรดน้ำ** น้ำยังซึมไม่ทั่ว รอสัก 10 นาทีค่อยอ่าน
