## ภาพรวม

มอเตอร์แปรงถ่านกระแสตรง หมุนต่อเนื่องตราบที่ยังจ่ายไฟ ความเร็วขึ้นกับแรงดัน ทิศทางขึ้นกับ
ขั้วที่ป้อน ไม่มีวงจรควบคุมในตัว ต่างจากเซอร์โวซึ่งสั่งเป็นมุมได้

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| แรงดันใช้งาน | รุ่น 3 V, 5 V หรือ 12 V (เลือกได้ในแผงด้านขวา) ต่ำกว่าครึ่งหนึ่งไม่หมุน |
| กระแสขณะไม่มีโหลด | ราว 70 mA |
| กระแสขณะมีโหลด | 200–400 mA |
| กระแสตอนแกนถูกล็อก | สูงถึง 1 A |
| ความเร็ว | ราว 8000 รอบต่อนาทีที่ 6 V ไม่มีโหลด |

## ต่อเข้าขา GPIO โดยตรงไม่ได้

ขา GPIO จ่ายได้ 40 mA ส่วนมอเตอร์กินอย่างน้อย 200 mA ต่อตรงแล้วขาบอร์ดพังทันที ต้องใช้
ทรานซิสเตอร์หรือไดรเวอร์คั่น

วงจรที่ง่ายที่สุดคือทรานซิสเตอร์ NPN ตัวเดียว ควบคุมความเร็วได้ทางเดียวไม่กลับทิศ

```
                    ┌──────── ไฟเลี้ยงมอเตอร์ +
                    │
                 [มอเตอร์]
                    │
       ┌────────────┼──── ขั้วบวกของไดโอด
       │            │
    [ไดโอด]      คอลเลกเตอร์
   1N4007           │
       │        ทรานซิสเตอร์ NPN
       └────────────┤
GPIO ──[1 kΩ]── เบส │
                 อิมิตเตอร์
                    │
                   GND (ต่อร่วมกับกราวด์บอร์ด)
```

## ไดโอดคร่อมมอเตอร์คือสิ่งจำเป็น

ขดลวดในมอเตอร์เก็บพลังงานแม่เหล็กไว้ เมื่อตัดกระแสกะทันหัน พลังงานนั้นออกมาเป็นแรงดัน
ย้อนกลับที่สูงหลายสิบโวลต์ ซึ่งทำลายทรานซิสเตอร์ได้ในครั้งเดียว

ไดโอด 1N4007 คร่อมขั้วมอเตอร์ โดยให้แถบสีอยู่ทางไฟบวก จะเปิดทางให้กระแสนั้นวนกลับใน
ขดลวดจนหมดพลังงานแทน **ห้ามละเว้นชิ้นนี้**

## กลับทิศต้องใช้วงจรสะพาน

ทรานซิสเตอร์ตัวเดียวสั่งได้แค่หมุนกับหยุด การกลับทิศต้องสลับขั้วที่ป้อน ซึ่งต้องใช้วงจรสะพาน
เอชสี่ตัวหรือไดรเวอร์สำเร็จรูปอย่าง L298N หรือ L293D

## ควบคุมความเร็วด้วย PWM

```cpp
const int MOTOR_PIN = 25;

void setup() {
  pinMode(MOTOR_PIN, OUTPUT);
}

void setSpeed(int percent) {
  // ต่ำกว่าราว 30% มอเตอร์จะสั่นแต่ไม่หมุน แรงบิดไม่พอชนะแรงเสียดทาน
  int duty = map(constrain(percent, 0, 100), 0, 100, 0, 255);
  analogWrite(MOTOR_PIN, duty);
}
```

การสตาร์ตจากหยุดควรสั่งเต็มกำลังสั้น ๆ ก่อนลดลงมาที่ความเร็วที่ต้องการ ไม่งั้นมอเตอร์อาจไม่
เริ่มหมุนเลยที่ค่าต่ำ

## สัญญาณรบกวนจากแปรงถ่าน

แปรงถ่านสร้างประกายไฟตลอดเวลาที่หมุน ซึ่งเป็นสัญญาณรบกวนที่ทำให้บอร์ดรีสตาร์ตหรือเซนเซอร์
อ่านค่าเพี้ยน วิธีลด: บัดกรีตัวเก็บประจุเซรามิก 100 nF คร่อมขั้วมอเตอร์ และเดินสายมอเตอร์แยก
จากสายสัญญาณ

## ปัญหาที่พบบ่อย

- **บอร์ดรีสตาร์ตทุกครั้งที่มอเตอร์เริ่มหมุน** ใช้แหล่งจ่ายแยกและต่อกราวด์ร่วม
- **ทรานซิสเตอร์ร้อนจัด** กระแสเกินพิกัด หรือขับเบสไม่แรงพอจนทรานซิสเตอร์ทำงานครึ่งทาง
- **มอเตอร์สั่นแต่ไม่หมุน** ค่า PWM ต่ำเกินไป
- **เซนเซอร์อ่านค่าเพี้ยนเฉพาะตอนมอเตอร์ทำงาน** ใส่ตัวเก็บประจุคร่อมมอเตอร์
