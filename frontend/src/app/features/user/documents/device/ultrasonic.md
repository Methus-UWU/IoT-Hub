## ภาพรวม

วัดระยะด้วยการยิงคลื่นเสียงความถี่ 40 kHz ออกไปจากตัวส่ง แล้วจับเวลาจนกว่าเสียงจะสะท้อน
กลับมาถึงตัวรับ ระยะคำนวณจากเวลาคูณความเร็วเสียงหารสอง เพราะเสียงเดินทางไปกลับ

## ข้อมูลจำเพาะ

| หัวข้อ | ค่า |
| --- | --- |
| ช่วงวัด | 2–400 ซม. |
| ความละเอียด | ประมาณ 3 มม. |
| มุมลำเสียง | 15 องศา |
| กระแสขณะทำงาน | 15 mA |
| ความถี่วัดสูงสุด | ราว 20 ครั้งต่อวินาที |

## ลำดับสัญญาณ

1. ส่งพัลส์สูงที่ขา `TRIG` นาน 10 ไมโครวินาที
2. โมดูลยิงเสียง 8 ลูกที่ 40 kHz ออกไปเอง
3. ขา `ECHO` ขึ้นสูง แล้วลงต่ำเมื่อได้รับเสียงสะท้อน
4. ความกว้างของพัลส์ที่ `ECHO` คือเวลาไปกลับเป็นไมโครวินาที

ระยะเป็นเซนติเมตรได้จาก `เวลา / 58` ตัวเลข 58 มาจากความเร็วเสียง 340 เมตรต่อวินาที
หารสองแล้วแปลงหน่วย

## ต่อกับ ESP32 ต้องลดแรงดัน

โมดูลนี้ทำงานที่ 5 V และขา `ECHO` ส่งออก 5 V ซึ่งเกินที่ขา GPIO ของ ESP32 รับได้ ต่อตรงแล้ว
ขาบอร์ดจะเสียหายสะสมจนพัง ให้ผ่านตัวแบ่งแรงดันก่อน

```
ECHO ──[ 1 kΩ ]──┬── GPIO
                 │
              [ 2 kΩ ]
                 │
                GND
```

ขา `TRIG` ต่อตรงได้ เพราะโมดูลอ่านค่า 3.3 V เป็นลอจิกสูงอยู่แล้ว ถ้าใช้กับ Arduino Uno
ซึ่งเป็นบอร์ด 5 V ต่อตรงได้ทั้งสองขา

## ตัวอย่างโค้ด

```cpp
const int TRIG_PIN = 5;
const int ECHO_PIN = 18;

void setup() {
  Serial.begin(115200);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
}

long readDistanceCm() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  // หมดเวลาที่ 25000 ไมโครวินาที ราว 4 เมตร ไม่งั้นจะค้างเมื่อไม่มีเสียงสะท้อน
  unsigned long duration = pulseIn(ECHO_PIN, HIGH, 25000UL);
  if (duration == 0) return -1;
  return duration / 58;
}
```

ค่าหมดเวลาใน `pulseIn` สำคัญมาก ถ้าไม่ใส่ ฟังก์ชันจะรอนานถึงหนึ่งวินาทีเมื่อยิงเสียงออกไปแล้ว
ไม่มีอะไรสะท้อนกลับ ซึ่งทำให้ทั้งลูปหยุดค้าง

## ปัญหาที่พบบ่อย

- **ได้ค่า 0 หรือค่าติดลบ** ไม่มีเสียงสะท้อนกลับ อาจไกลเกิน 4 เมตร หรือผิวเป้าหมายดูดซับเสียง
- **ค่ากระโดดไปมา** ให้อ่านสามครั้งแล้วใช้ค่ากลาง วิธีนี้ตัดค่าผิดปกติได้ดีกว่าการเฉลี่ย
- **วัดผ้า ฟองน้ำ หรือขนสัตว์ไม่ได้** วัสดุพวกนี้ดูดซับเสียงจนไม่มีคลื่นสะท้อน
- **ผิวเอียงเกิน 45 องศาวัดไม่ได้** เสียงสะท้อนออกไปทางอื่นแทนที่จะกลับมาที่ตัวรับ
- **ค่าเพี้ยนตามอุณหภูมิ** ความเร็วเสียงเปลี่ยนราว 0.6 % ต่อ 1 °C งานที่ต้องแม่นยำต้องชดเชย
