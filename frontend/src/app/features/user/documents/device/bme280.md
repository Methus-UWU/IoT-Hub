# BME280

เซนเซอร์วัดอุณหภูมิ ความชื้น และความกดอากาศ เหมาะกับสถานีอากาศ
โมดูลที่จำลองใช้ 3.3 V และ I2C ต้องต่อทั้ง SDA/SCL และกราวด์ร่วม
เลือก address 0x76 หรือ 0x77 ใน inspector ให้ตรงกับ sensor.begin

```cpp
#include <Wire.h>
#include <Adafruit_BME280.h>
Adafruit_BME280 sensor;
bool ready = false;
void setup() {
  Serial.begin(115200); Wire.begin();
  ready = sensor.begin(0x76);
}
void loop() {
  if (ready) {
    Serial.println(sensor.readTemperature());
    Serial.println(sensor.readHumidity());
    Serial.println(sensor.readPressure() / 100.0);
  }
  delay(1000);
}
```

readPressure คืนค่า Pa จึงหาร 100 เพื่อแสดง hPa
ตัวอย่าง BME280 พร้อม LCD อยู่ใน `frontend/examples/weather-lcd`
เปิด simulator แล้วปรับอุณหภูมิ ความชื้น หรือความกดอากาศจาก inspector
LCD จะเปลี่ยนตามค่าที่ firmware อ่าน

ตัวจำลองรองรับ I2C และค่าที่ผู้ใช้กำหนด ยังไม่มี calibration registers,
filtering หรือ sampling timing ถ้าถอดสายหรือ address ไม่ตรง begin จะคืน false
และอ่านค่าได้ NAN

อ้างอิง API: [Adafruit BME280](https://github.com/adafruit/Adafruit_BME280_Library)
